# Premium Landing Prototype Pipeline

Версия 4. Набор промптов для прототипа лендинга: от текста к прототипу, арт-дирекшну, Hi-Fi, визуальным материалам и сборке страницы, плюс сборщик промптов для изображений разделов. Работает для любого продукта.

Проверяющих нет ни на одном этапе: автор каждого этапа сам проходит свой чек-лист без оценок и исправляет найденное. Технические проверки сборки страницы остаются.

## Этапы по порядку

1. [Мастер-промпт — премиальный прототип лендинга.md](Мастер-промпт%20—%20премиальный%20прототип%20лендинга.md) — полный прототип из текста, продукта и референсов. Самопроверка — раздел 19.
2. [Промпт — поиск арт-дирекшна лендинга.md](Промпт%20—%20поиск%20арт-дирекшна%20лендинга.md) — пять независимых направлений на основе прототипа; победителя этап не выбирает. Самопроверка — раздел «Самопроверка».
3. [Universal Hi-Fi Design & Production Polish.md](Universal%20Hi-Fi%20Design%20&%20Production%20Polish.md) — выбранное направление в точную статическую систему страницы. Самопроверка — раздел 16 и «Definition of Done».
4. [Universal Visual Asset Production Orchestrator.md](Universal%20Visual%20Asset%20Production%20Orchestrator.md) — финальные визуальные материалы. Самопроверки — Phase 6 (каждый главный материал), Phase 7 (три главных вместе), раздел 20 (второстепенные), раздел 23 (вся система).
5. [Universal Asset-to-Page Assembly & Integration Orchestrator.md](Universal%20Asset-to-Page%20Assembly%20&%20Integration%20Orchestrator.md) — сборка материалов в страницу. Технические проверки — раздел 15 (реальная отрисовка на пяти ширинах) и раздел 21 (целостность сборки); самопроверка — разделы 18–19.

[Universal Visual Story & Asset Production.md](Universal%20Visual%20Story%20&%20Asset%20Production.md) — вариант, в котором производство материалов и встраивание в страницу идут одним этапом вместо этапов 4 и 5. Самопроверка — раздел 17.

## Промпты изображений разделов

- [Промпт-сопоставления-элементов-лендинга.md](Промпт-сопоставления-элементов-лендинга.md) — какие визуальные объекты референса нужны целевому разделу. Проверка полноты — шаг 5.
- [00_Как_собрать_промпт_раздела.md](00_Как_собрать_промпт_раздела.md) — как работает сборка метапромпта раздела; команды — [README_Сборка_мастерпромпта.md](README_Сборка_мастерпромпта.md).
- `01`–`06`, `standalone_template.md`, `categories.json` — общие правила, мастер раздела и модули категорий. Самопроверка готового промпта — `01_Общие_правила_метапромпта.md`, раздел «Самопроверка готового промпта».
- `Промпт_для_создания_*.md` — автономные версии для одного элемента; собираются скриптом, вручную не правятся.
- `build_prompt.py`, `test_build_prompt.py` — сборщик и его тесты; `holdi-control-example/` — контрольный пример одного продукта для тестов.
