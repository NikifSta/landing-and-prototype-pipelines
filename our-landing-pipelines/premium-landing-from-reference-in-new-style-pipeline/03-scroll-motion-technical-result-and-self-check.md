# Этап 3. Движение, технический результат и самопроверка

Третья часть промпта этапа 3; первая — `03-build-page-around-anchor-visuals-with-scroll-motion.md`, вторая — `03-zone-placement-product-ui-and-design-system.md`. Читай все три до начала работы.

# 11. Движение при прокрутке

Движение делается на этом этапе по «Правилам визуалов и движения», раздел «Движение при прокрутке»:
- для каждой секции возьми приём по «Правилам визуалов и движения» и запиши его в Execution её зон;
- доведи фишку выбранного направления на всю кульминацию: самый длинный отрезок прокрутки, тихая секция перед ней;
- опорные визуалы и интерфейсы двигай слоями;
- для зон, которые сделает этап 4, задай движение заранее: приём, отрезок прокрутки, какие слои движутся;
- телефон и выключенная анимация — по тем же правилам.

Проверь страницу съёмщиком scroll-craft (команды — в README пайплайна, раздел «Проверка прокруткой») на 1440 px, на 390 px и с выключенной анимацией и посмотри листы кадров: движение читается, нет мёртвой прокрутки, кульминация — самое большое изменение на странице, последняя секция завершает страницу.

---

# 12. Технический результат

Создай **одну полную работающую high-fidelity версию всего лендинга с движением**.

Основной результат:

- HTML;
- CSS;
- JavaScript движения: движок scroll-craft без правок и код фишки;
- десктоп и телефон;
- finalized typography / grid / spacing / surfaces;
- structural Product UI states там, где они нужны;
- три опорных визуала слоями в папке визуалов;
- аннотации зон с заполненным Placement.

**Визуалы остальных зон не являются результатом этого этапа.**

Если они есть среди реальных материалов продукта, используй их как входные данные, но не создавай их с нуля вместо этапа 4.

---

# 13. Финальная самопроверка Hi-Fi

После первой реализации проверь всю страницу по критериям, без оценок:

1. Art-direction fidelity
2. Visual hierarchy
3. Composition
4. Typography
5. Grid precision
6. Whitespace / restraint
7. Page rhythm
8. Signature-element consistency
9. Product-storytelling architecture
10. Quality of visual zones
11. Product UI architecture
12. Brand distinctiveness
13. Готовность к этапу 4
14. Телефон
15. Движение: у каждой секции свой приём, фишка работает, при выключенной анимации страница полная
16. Опорные визуалы: прошли проверку отдельно и в странице, язык визуалов записан

Дополнительно ответь:

> **Если автор этапа 4 получит эту страницу, сможет ли он сделать остальные визуалы по аннотациям и языку визуалов, не переделывая страницу?**

Если ответ «нет» — Hi-Fi ещё не закончен.

Если по какому-то критерию страница слабая, исправь несколько наиболее фундаментальных проблем.

# Definition of Done

Этап считается завершённым, когда:

- проработан весь лендинг;
- сохранена исходная концепция арт-дирекшена;
- сформирована последовательная design system;
- десктоп и телефон решены и проверены на 1440 и 390 px;
- typography / grid / spacing / surfaces / hierarchy доведены до высокого уровня;
- у всех значимых зон заполнен Placement;
- Product UI architecture определена там, где она нужна;
- отсутствуют случайные псевдофинальные placeholder-решения;
- три опорных визуала сделаны слоями, язык визуалов записан;
- движение и фишка работают, страница проверена съёмщиком;
- финальная самопроверка пройдена, найденные фундаментальные проблемы исправлены;
- дальнейший качественный скачок требует визуалов остальных зон на этапе 4, а не ещё одной перестройки layout.

После этого остановись.

Следующий этап — этап 4: остальные визуалы и проверка прокруткой.

---

# Ключевая установка

**Этап 3 определяет страницу, её движение и опорные визуалы. Этап 4 создаёт содержимое остальных зон. Не смешивай эти ответственности.**

Страница уже должна обладать сильной системой и арт-дирекшеном, но не обязана притворяться, что отсутствующие production assets уже существуют.
