# Этап 3. Размещение визуалов, интерфейс и дизайн-система

Вторая часть промпта этапа 3; первая — `03-lay-out-page-around-approved-visuals.md`, третья — `03-scroll-motion-checks-and-result.md`. Читай все три до начала работы.

# 3. Размещение визуалов

Для каждого утверждённого визуала реши на странице:
- размеры и соотношение сторон на десктопе;
- фокус, безопасная область для текста, допустимое перекрытие;
- допустимое кадрирование; у интерфейса — по «Правилам визуалов и движения», раздел «Интерфейс продукта»;
- положение: во всю ширину, в контейнере или слоем;
- порядок слоёв визуала и текста;
- поведение на телефоне.

Текст — HTML поверх визуала или рядом с ним, никогда не внутри картинки или ролика. Текст над визуалом читается в каждом кадре прокрутки.

---

# 4. Интерфейс страницы и продукта

Экраны продукта уже сделаны этапом 2 как одна система. Если есть готовый дизайн приложения, они собраны из него по «Правилам визуалов и движения», раздел «Интерфейс продукта».

Элементы самой страницы — навигация, кнопки, формы, тарифы, controls — проектируй в одном языке с этими экранами: типографика, отступы, скругления, состояния и иконки не спорят с продуктом.

Не создавай новый вымышленный dashboard для какой-либо секции: продукт на странице — только утверждённые визуалы.

---

# 5. Design System

Сформируй последовательную систему всего лендинга.

## Typography

Определи:

- display;
- H1 / H2 / H3;
- body;
- captions;
- labels;
- button typography;
- line-height;
- tracking;
- max line lengths;
- responsive behavior.

## Layout

Определи:

- grid десктопа и телефона;
- content width;
- gutters;
- column behavior;
- section spacing;
- vertical rhythm;
- alignment rules;
- full-bleed behavior;
- overlap rules.

## Core UI

Определи:

- navigation;
- buttons;
- controls;
- forms;
- pricing;
- cards / containers, только если они действительно нужны;
- product surfaces.

## Visual Language

Определи:

- palette;
- accent usage;
- borders;
- radii;
- shadows;
- blur;
- gradients;
- depth;
- texture principles;
- imagery treatment по языку визуалов;
- iconography;
- signature element behavior.

Количество визуальных приёмов должно быть ограниченным.

Качество должно возникать из **точности, последовательности, отбора и restraint**, а не количества эффектов.

---

# 6. Signature Element

Signature element арт-дирекшна должен стать системным принципом.

Развивай его по странице:

- иногда как главный композиционный объект;
- иногда как spatial principle;
- иногда как background behavior;
- иногда как небольшая деталь;
- иногда как движение при прокрутке.

Он должен повышать узнаваемость, но не превращаться в gimmick.

---

# 7. Craft и визуальное качество

Особенно внимательно проработай:

- размеры и интервалы;
- line-height;
- длину строк;
- optical alignment;
- масштаб заголовков;
- whitespace;
- баланс текста и визуала;
- grid precision;
- surface hierarchy;
- borders / radii;
- shadow system;
- color relationships;
- masks / clipping logic;
- переходы между секциями;
- overall rhythm.

Не компенсируй слабое место страницы декоративной детализацией контейнера вокруг визуала.

Избегай ощущения autogenerated SaaS template.

Premium quality чаще возникает из **точного решения того, что оставить, а не того, что ещё добавить**.

Сюжет страницы — из разбора референса в плане, вид — арт-дирекшна плана; вид референса не переносится («Правила для всех этапов», раздел «Референс»).

# 9. Десктоп и телефон

Реши обе версии. Десктоп — главный макет; телефон — отдельная композиция, а не уменьшенный десктоп: порядок, масштаб заголовков, кадрирование визуалов, слои и плотность решаются заново для узкого экрана; телефонные версии визуалов — из этапа 2. Интерфейс на телефоне — по «Правилам визуалов и движения», раздел «Интерфейс продукта».
