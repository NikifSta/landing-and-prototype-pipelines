# Этап 1. Список визуалов, внимание, ритм, первый экран и показ продукта

Вторая часть промпта этапа 1; первая — `01-break-down-reference-and-plan-landing.md`, третья — `01-art-direction-plan-format-and-self-check.md`. Читай все три до начала работы.

# 8. Список визуалов

Для каждого визуала сначала реши, что он должен показать и какую мысль доказать; уже потом — формат и место.

Запиши в план список визуалов по порядку секций: у каждого — секция и задание по «Правилам для всех этапов», раздел «Задания на визуалы»: Visual Intent, Role, Execution.

Не оставляй выбор следующему автору: формулировки «интерфейс или схема», «фото или иллюстрация», «можно анимацию» — недоделанное задание. Если нужен интерфейс продукта, назови экран, его состояние, что в нём меняется по сценарию секции и что это доказывает — по «Правилам визуалов и движения», раздел «Интерфейс продукта». Для фото и видео запиши фразу из раздела «Фото и видео» тех же правил.

Отметь три опорных визуала — по ним этап 2 закрепит язык визуалов:
- A — главный визуал первого экрана;
- B — главный экран продукта или продуктовая сцена;
- C — визуал кульминации с фишкой референса; если кульминация уже в A или B — визуал другого типа: фотография, ролик, предметная сцена или иллюстрация.

Не ставь визуал только потому, что в секции есть место: одна важная мысль — одно сильное визуальное доказательство.

---

# 9. Спроектировать внимание

Для каждой крупной секции определи один главный визуальный фокус.

Пользователь должен быстро понимать:

- куда смотреть;
- что здесь главное;
- какую мысль нужно вынести;
- какое действие или переход ожидается дальше.

Создавай сильную иерархию через масштаб, пространство, контраст и композицию.

---

# 10. Создать ритм страницы

Страница должна иметь заметную смену:

- масштаба;
- плотности;
- композиции;
- количества информации;
- положения визуальных объектов;
- эмоциональной интенсивности.

Одни секции могут быть очень крупными и почти пустыми.

Другие — более информативными.

Соседние блоки должны отличаться композиционно, оставаясь частью одной системы.

Для каждой секции задай порядок блоков на телефоне.

---

# 11. Простота и редактура

На каждом этапе стремись к уменьшению количества визуального шума.

Каждый элемент должен:

- усиливать иерархию;
- помогать пониманию;
- поддерживать продуктовую историю;
- быть необходимым для страницы.

Если элемент не выполняет функцию, убери его.

Простота должна быть следствием точных решений, а не отсутствия дизайна.

---

# 12. Оригинальность

Ищи не декоративную необычность, а **сильную визуальную идею**.

Хорошее решение может быть неожиданным, но должно сразу помогать понять продукт.

Если есть выбор между оригинальностью и ясностью, выбирай ясность.

---

# 13. Первый экран

Первый экран должен быстро дать понять:

- что это за продукт;
- для кого он;
- какое главное обещание он делает;
- что пользователь может сделать дальше.

При этом первый экран не должен пытаться объяснить всё.

Его задача — дать сильное первое понимание и втянуть пользователя в дальнейшую историю.

Первый экран показывает обещание продукта, а не образец документа или интерфейса продукта.

---

# 14. Показ продукта

Показывай продукт через действие, изменение состояния, причинно-следственную связь, процесс и результат, а не только через статичный скриншот интерфейса.

В зависимости от продукта естественный сценарий может выглядеть, например: проблема → действие → работа продукта → результат; ввод → обработка → результат; до → во время → после; объект → трансформация → новый объект; данные → анализ → решение; событие → реакция системы → эффект.

Это не готовые шаблоны. Найди естественную историю именно конкретного продукта. Визуальное представление должно помогать понять продукт ещё до подробного чтения текста.
