# Этап 3. Движение, проверки и результат

Третья часть промпта этапа 3; первая — `03-lay-out-page-around-approved-visuals.md`, вторая — `03-visual-placement-product-ui-and-design-system.md`. Читай все три до начала работы.

# 10. Движение при прокрутке

Движение — по «Правилам визуалов и движения», раздел «Движение при прокрутке»:
- движение каждого визуала из витрины привязывается к прокрутке страницы с приёмом и отрезком из его Execution;
- фишка арт-дирекшна занимает всю кульминацию: самый длинный отрезок прокрутки, тихая секция перед ней;
- текст секции движется вместе с визуалом так, чтобы читаться в каждом кадре;
- телефон и выключенная анимация — по тем же правилам.

---

# 11. Страница целиком

Прокрути страницу сверху вниз. Проверь:
- ритм плана сохранился: есть кульминация, паузы и развитие;
- нет одинакового масштаба всех визуалов, бесконечного «текст слева — картинка справа», слишком частого акцента, конкурирующих фокусов;
- продукт выглядит одним настоящим продуктом в разных состояниях;
- сильные визуалы не уменьшены до миниатюр.

Если красивый визуал ухудшает страницу — исправляй кадрированием, масштабом, окружением и положением. Если этого мало — запиши в `stage-notes.md`, какой визуал и почему мешает: визуалы утверждены, и решение о них принимает Иван.

---

# 12. Технические проверки

Реальная отрисовка на 1440, 1024, 768, 430 и 390 px:
- нет горизонтального переполнения, случайной обрезки и битых изображений, роликов, SVG или ссылок;
- все секции, тексты и CTA на месте, порядок сохранён;
- основной текст читается; интерфейс на телефоне — по «Правилам визуалов и движения», раздел «Интерфейс продукта»;
- фокус визуала и допустимое кадрирование сохраняются на телефоне;
- телефон — настоящий узкий экран, а не уменьшенный снимок десктопа;
- страница визуально чистая: служебных подписей витрины и технических меток нет.

Проверка прокруткой — съёмщиком scroll-craft по README пайплайна, раздел «Проверка прокруткой»: 1440 px, 390 px и выключенная анимация. По отчёту и листам кадров:
- нет мёртвой прокрутки и подсказок, которые не становятся полностью видимыми;
- ролики идут вместе с прокруткой, обложка совпадает с первым кадром;
- слои движутся с разной скоростью без дыр, двойников и ореолов;
- текст над визуалами читается в каждом кадре;
- кульминация — самое большое изменение на странице, последняя секция завершает страницу;
- при выключенной анимации страница полная и статичная.

Реальный телефон съёмщик не проверяет: так и напиши в итогах.

---

# 13. Итоговая самопроверка

Проверь страницу целиком по критериям, без оценок:

1. Верность арт-дирекшну плана
2. Visual hierarchy
3. Composition
4. Typography
5. Grid precision
6. Whitespace / restraint
7. Page rhythm
8. Signature-element consistency
9. Понятность рассказа и показ продукта
10. Правдоподобие продукта и людей, если они есть
11. Единство визуального мира страницы и визуалов
12. Brand distinctiveness
13. Телефон
14. Движение: приёмы секций читаются, фишка работает, при выключенной анимации страница полная
15. Ощущение законченной премиальной страницы

Если по критерию страница слабая, внеси несколько изменений с наибольшим влиянием на всю страницу. Не трать доработку на редкие случаи и мелочи.

---

# 14. Результат

- страница `stage-3/<продукт>-landing.html` с движком scroll-craft, CSS и JavaScript движения;
- папка визуалов `stage-3/visuals/` — копия утверждённых визуалов этапа 2 с правками кадрирования, если они были;
- листы кадров проверки прокруткой в `stage-3/lab/`;
- раздел «Этап 3» в `stage-notes.md`: отклонения визуалов от этапа 2, что переделано и почему, визуалы, которые мешают странице, что не проверено (реальный телефон), известные риски.

## Definition of Done

Этап считается завершённым, когда:

- проработана вся страница от первого экрана до footer;
- сохранён арт-дирекшн плана, все утверждённые визуалы на месте;
- сформирована последовательная design system;
- десктоп и телефон решены и проверены на пяти ширинах;
- typography / grid / spacing / surfaces / hierarchy доведены до высокого уровня;
- движение и фишка работают, страница проверена съёмщиком;
- итоговая самопроверка пройдена, найденные фундаментальные проблемы исправлены.

После этого остановись.
