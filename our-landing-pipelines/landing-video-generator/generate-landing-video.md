# Ролик под прокрутку для визуальной зоны лендинга

Сделай один ролик для одной зоны типа «видео под прокруткой»: закажи первый кадр, опиши движение камеры, сгенерируй ролик в двух форматах, перекодируй под прокрутку и сделай обложки. Один проход; варианты на выбор не возвращай.

## Вход

От этапа 2, 3 или 4 пайплайна лендинга:
- аннотация зоны: Visual Intent, Role, Execution (что меняется при прокрутке), Placement, если он уже есть;
- тексты секции рядом с зоной — контекст, в ролик не входят;
- `stage-notes.md` и `landing-pipeline-rules-for-all-stages.md`;
- стиль — как для изображения (`../landing-image-generator/generate-landing-image.md`, раздел «Вход»);
- вложения, папка результата `ZONE_DIR` и идентификатор зоны `ZONE`.

## 1. Границы

Смысл зоны и тип визуала не меняй. В ролике нет текста, логотипов и надписей: текст страницы — HTML поверх ролика. Звук не нужен.

## 2. Первый кадр — пайплайн изображений

Закажи два кадра агентам с промптом `../landing-image-generator/generate-landing-image.md`, слои — «без слоёв»: `<зона>-start-16x9` — 16:9 для компьютера и `<зона>-start-9x16` — 9:16 для телефона. В задании укажи, что это первый кадр ролика: в сцене должно быть куда двигаться камере, место под текст — там, где текст стоит на странице.

Seedance может отклонить фотореалистичных людей: если по Visual Intent люди не обязательны, держи их вне кадра или вдали.

Если кадр не прошёл сверку пайплайна изображений, ролик не делай и верни вызвавшему причину.

## 3. Движение камеры

Для каждого формата напиши английский промпт из 2–4 предложений в `$ZONE_DIR/$ZONE-16x9-motion-prompt.txt` и `$ZONE_DIR/$ZONE-9x16-motion-prompt.txt`:
- одно непрерывное движение камеры — медленный наезд, облёт, подъём или проход сквозь сцену — без склеек;
- что меняется в сцене за ролик — то, что Execution требует показать при прокрутке;
- ролик начинается с кадра; новых заметных объектов, людей, текста и логотипов не появляется;
- ровный темп без рывков: время ролика будет идти вместе с прокруткой в обе стороны.

## 4. Генерация — Seedance 2.5 в Dreamina

Нужна сессия Chrome со входом в Dreamina; если её нет:

```bash
~/google-login-automation/venv/bin/python ~/.claude/skills/real-chrome-web-navigator/scripts/launch-real-chrome-session.py
```

Для каждого формата из корня проекта:

```bash
cd /home/ivan/claude-sandbox/hypothesis-tester
.venv/bin/python dev/pipelines/landing-video-generator/tools/landing_scroll_clip_dreamina_renderer.py \
  --start-frame "<файл кадра 16:9>" --prompt-file "$ZONE_DIR/$ZONE-16x9-motion-prompt.txt" \
  --aspect-ratio 16:9 --duration-seconds 5 --output-clip "$ZONE_DIR/$ZONE-16x9-raw.mp4"
```

То же для 9:16 с файлами `9x16`. Длительность — 5 секунд, если Execution не требует другой (4–30). Разрешение по умолчанию — наивысшее из предложенных Dreamina. Цена при разрешении по умолчанию, 1080P, — около 91 кредита Dreamina за секунду, ролик 5 секунд — около 455; перед отправкой скрипт сверяет баланс с ценой выбранного разрешения. При сбое скрипт сам зовёт ЛЛМ-ремонтника и повторяет рендер, если ничего не списано (README, «Самопочинка скрипта»); вызов тогда идёт до часа — запускай с таким таймаутом или в фоне и жди окончания. Если скрипт всё же остановился (нет кредитов, нет сессии, Dreamina отклонила кадр, починка не удалась), ничего не подменяй и верни вызвавшему его сообщение.

## 5. Перекодировка под прокрутку и обложки

Обычное видео при перемотке прокруткой дёргается; частые ключевые кадры это исправляют и убирают звук:

```bash
bash .claude/skills/scroll-craft/scripts/encode.sh "$ZONE_DIR/$ZONE-16x9-raw.mp4" "$ZONE_DIR/$ZONE-16x9.mp4"
ffmpeg -y -hide_banner -loglevel error -i "$ZONE_DIR/$ZONE-9x16-raw.mp4" -vf "scale=720:-2" \
  -c:v libx264 -crf 20 -g 4 -pix_fmt yuv420p -an -movflags +faststart "$ZONE_DIR/$ZONE-9x16.mp4"
for format in 16x9 9x16; do
  ffmpeg -y -hide_banner -loglevel error -i "$ZONE_DIR/$ZONE-$format.mp4" -frames:v 1 -q:v 2 \
    "$ZONE_DIR/$ZONE-$format-poster.jpg"
done
```

Обложка — первый кадр самого ролика, а не отдельная генерация: иначе в момент старта видео будет скачок.

## 6. Сверка

Для каждого формата сделай лист кадров и посмотри его:

```bash
ffmpeg -y -hide_banner -loglevel error -i "$ZONE_DIR/$ZONE-16x9.mp4" \
  -vf "fps=2,scale=480:-2,tile=5x2" -frames:v 1 "$ZONE_DIR/$ZONE-16x9-sheet.jpg"
```

Проверь:
- ролик начинается с заказанного кадра;
- движение одно, плавное, без склеек, рывков и «плывущих» объектов;
- не появилось новых объектов, людей, текста и логотипов;
- место под текст свободно на всём протяжении.

При расхождении уточни промпт движения и сгенерируй формат заново, не больше одного раза: каждая попытка тратит кредиты. Затем оставь лучший вариант и опиши отклонение.

## 7. Ответ

Одна строка для поля Result: файлы роликов и обложек обоих форматов, движение одной фразой, отклонения или «без отклонений».
