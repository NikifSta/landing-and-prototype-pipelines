# Как сделать лендинг: инструкция на понедельник

Предполагается, что папка `landing-pipeline` установлена по [INSTALL.md](INSTALL.md) и открыта в приложении Claude (вкладка Code).

## 1. Что делает плагин
Из описания гипотезы продукта за **11 этапов** собирает готовый лендинг: исследует сайты-образцы, пишет сценарий, придумывает название и фирменный стиль, генерирует картинки, верстает интерфейсы продукта с анимацией, собирает страницу и сам проверяет её на ошибки. Каждая новая страница получается **непохожей на прошлые**: плагин помнит все сделанные страницы и не повторяет их.

Готовые страницы прошлых запусков открываются по их страницам запуска (ссылка — в `checklist.md` проекта, пункт 11).

## 2. Самый простой запуск: «ничего не вводить и пойти по делам»
Если тема не важна, введите **одну команду** без описания:
```
/run --auto
```
Плагин сам придумает тему нового продукта (непохожую на уже сделанные страницы), сам ответит на все вопросы и дойдёт до готовой страницы. Всё придуманное записывается в `decisions.md`.

Если нужна своя тема, добавьте описание (подставьте свою гипотезу):
```
/run --auto Мобильное приложение для общего бюджета пары: траты с карт обоих в одной ленте, цели накоплений. Можно картинки и 3D, видео не нужно, тестовые цены разрешены.
```
Как написать хорошее описание (3 предложения):
1. **Что за продукт и для кого** («приложение для общего бюджета пары»).
2. **Какую проблему решает** («не нужно выяснять, кто сколько потратил»).
3. **Ограничения:** что можно генерировать (картинки, 3D, видео), бюджет на видео в кредитах Dreamina, можно ли использовать тестовые цены, что не нравится («без бежевого и тёмного»).

Дальше **ничего делать не нужно** (если сессия работает без запросов разрешений). Плагин сам:
- выберет референсы и вариант рецепта, записывая причины в `projects/<проект>/decisions.md`;
- заполнит цены и другие данные, которых нельзя придумать, **тестовыми значениями**; на самой странице об этом ничего не написано, список тестовых значений придёт в чат и лежит в `open-questions.md`;
- запишет время каждого этапа в `timings.md`.

**Сколько ждать:** обычно 1,5–2,5 часа; изображения — в подписке ChatGPT, видео — кредиты Dreamina. Сессия Claude на это время должна оставаться открытой. Если лимит Claude подходит к концу, плагин остановится и сохранит состояние (см. раздел 6).

## 2б. Режим «сначала отвечу я, дальше без меня»
```
/run --ask
```
Плагин покажет **одно сообщение с десятью вопросами** и доску вкуса (8 картинок со ссылками на сайты): тема; название и фирменный стиль; главное действие кнопки; язык и рынок; что нравится на доске и свои примеры; что можно генерировать и бюджет; чего не хочется видеть; цены (или «тестовые»); материалы продукта (скриншоты, тексты, цифры, логотип); нужен ли мокап устройства (телефон, ноутбук, планшет) или без мокапов. По каждому пункту указан ответ по умолчанию, можно написать «всё по умолчанию». После вашего ответа вопросов больше нет: плагин сам выберет вариант рецепта по вашим ответам и дойдёт до готовой страницы.

## 3. Пошаговый запуск (если хочется выбирать самому по ходу)
```
/run Приложение для общего бюджета пары
```
Тогда плагин задаст два вопроса и остановится в трёх местах:
1. **Доска вкуса** (этап 1): покажет 8 картинок сайтов и **ссылки на них** (можно зайти и посмотреть живую страницу); ответьте, какие нравятся и какие нет, и что именно (цвет, шрифт, первый экран).
2. **Три варианта рецепта A/B/C** (этап 3): картинка и описание каждого; ответьте буквой («B»), можно «B, но без видео».
3. **Цены, сроки, гарантии** — данные, которые нельзя придумать. Можно ответить «позже»: страница соберётся с заглушками.

Запускать этапы по отдельности тоже можно: `/intake`, `/story`, `/build` и так далее.

## 4. Что вы увидите по ходу
Claude пишет короткие итоги этапов. Все файлы лежат в `landing-work/projects/<название-проекта>/`:
| Файл или папка | Что это |
|---|---|
| `site/index.html` | **готовая страница**: откройте двойным щелчком |
| `checklist.md` | на каком из 11 этапов остановились |
| `decisions.md` | какие решения принял плагин и почему |
| `timings.md` | сколько времени занял каждый этап |
| `qa/report.md` | результаты автоматической проверки |
| `open-questions.md` | какие значения тестовые и требуют подтверждения |
| `06-art-direction.md` | дизайн-план страницы |
| `07-media/` | сгенерированные картинки |

Посмотреть страницу с телефона: откройте ссылку страницы запуска из итогового сообщения (раздел «Страница») — она одна для компьютера и телефона.

## 5. Как вносить правки
Просто напишите Claude, что не нравится, конкретно по блоку:
```
В блоке «Сколько стоит» карточки слишком похожи на обычные тарифы. Сделай цену как предмет, а не карточку.
Кнопку «Скачать» в первом экране сделай крупнее.
Замени аватарки с буквами на фотографии.
```
Claude исправит страницу и пересоберёт её. Хорошее замечание: **что не так + как должно быть** (можно приложить скриншот). Если замечание общее (например, «текст прижат к краю карточки»), попросите: «запомни это как правило»: оно попадёт в `CLAUDE.md` и больше не повторится в следующих лендингах.

## 6. Если закончился лимит Claude
Подождите сброса (время сброса показывает приложение) и введите:
```
/run <имя папки проекта из projects/>
```
Прогон продолжится с первого неотмеченного этапа (по `checklist.md`).

## 7. Публикация и деньги
- **Публикация:** после завершения страница сразу выкладывается на страницу запуска `https://my.holdi.ai/prototypes/<проект>-<код>/` (ссылка — в итоговом сообщении). Это один адрес для компьютера и телефона; страница открывается без входа, но адрес нельзя подобрать — пересылайте его только тем, кому нужно показать. Правки выкладываются по той же ссылке.
- **Тестовые значения** (цены, сроки, ссылки магазинов) нужно подтвердить или заменить перед публикацией: список в `open-questions.md`.
- **Стоимость:** изображения рисует Astra через Codex — в рамках подписки ChatGPT. Видео — Seedance 2.5 в Dreamina, около 455 кредитов за 5 секунд в 1080P: плагин включает его, только если оно действительно нужно теме, и называет цену заранее. Баланс кредитов виден на сайте Dreamina.

## 8. Частые вопросы
| Вопрос | Ответ |
|---|---|
| Страница вышла слабой (смотрите раздел «Рекомендации по улучшению» в итоговом сообщении) | напишите, какие блоки не нравятся; плагин переделает блок по референсу. Первый вариант обычно 7–8 из 10, после 2–3 кругов правок выше |
| Плагин остановился с ошибкой сети | повторите команду `/run <папка проекта>`: прогон продолжится |
| Сайт-аналог не открывается | плагин сам пробует архивную копию; можно задать `PROXY=` в `.env` |
| Как запустить второй лендинг | снова `/run --auto ...` с новой гипотезой: рецепт будет другим |
| Чем генерируются картинки и видео | Astra через Codex (вход ChatGPT) и Seedance 2.5 в Dreamina (Chrome навигатора); ключей в `.env` нет |
