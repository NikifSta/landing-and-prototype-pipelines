# Паспорт референса: Clutch

- **URL:** https://www.clutch.security/
- **Направление:** деловой, технологичный (строгий светлый enterprise-security с 3D-объектами)
- **Для каких продуктов подходит:** кибербезопасность, enterprise B2B, платформы управления доступом и инфраструктурой; когда нужен спокойный «взрослый» тон
- **Скриншоты:** `references/shots/clutch/shots/0-mobile.png` (снят вручную). Десктоп: `shots/2026-10-06_15-11-31.png` (снят вручную 06.10.2026) и ручная запись `motion/Вручную.Clutch _ Desktop.mp4`; мобильная запись — `motion/Вручную.Clutch _ Mobile.mp4`; кадры — `motion/manual-frames/`. Тексты в `pages.json` пустые — заголовки и тексты ниже взяты из HTML страницы 06.10.2026. Движение — `motion/`.

## Центральная идея
«Every Identity. Every Agent. Every Secret.»: невидимые нечеловеческие учётки и ИИ-агенты показаны как физические объекты — чёрные глянцевые 3D-«фишки» и платформа-диск, вокруг которого вращаются иконки сервисов. Хаос → один контролируемый центр.

## Сигнатурный приём
- Hero-объект: чёрная платформа-диск с логотипом-щитом в центре, по кругу — «таблетки» с иконками сервисов (AWS, GitHub, Okta…), часть подсвечена синим.
- Заголовок из трёх фраз, где активная фраза чёрная, остальные серые — подсветка переходит по фразам.
- Триада объектов «Human Identities → AI Agents → Non-Human Identities» с пилюлями-связями «Delegate to ▾ / Consume ▾» и плашками MANAGED / MULTIPLYING / 100X MORE THAN HUMANS.
- Синий световой «веер» в блоке интеграций — логотипы сервисов разлетаются по дуге.

## Композиция и сетка
- Узкая центральная колонка ≈900 px в рамке из тонких вертикальных линий (страница как «лист»), секции разделены горизонтальными линиями.
- Hero и ключевые заголовки по центру; секции фич — 2 колонки (заголовок + список ссылок со стрелками ›).
- Схема «Identity Lineage» — вертикальная цепочка пилюль (Person → Agent → Tools → Identities → Resources) с логотипами.
- Вкладки Identities / AI Agents / Secrets; «The Clutch Approach» — 3 колонки; «Instant Setup» — веер логотипов + 3 колонки; отзыв с вкладками-логотипами клиентов; «Recognized by» — бейджи наград; крупный вордмарк в футере.

## Типографика
- Нейтральный гротеск (по виду близко к Inter Display / Suisse Int'l), заголовки ≈36 px medium, плотный межстрочный.
- Плашки-ярлыки капсом с разрядкой ≈11 px.
- Аналог с кириллицей: **Inter** / **Inter Display**.

## Цвет
- Белый фон, чёрный текст, серый (≈#BDBDBD) для неактивных фраз.
- Акцент — электрический синий (≈#1F4BFF): плашки-ярлыки, подсветка «таблеток», световой веер.
- Чёрные кнопки «Book a demo».

## Изображения
- 3D-рендеры глянцевых чёрных объектов (диск-платформа, фишки, «машинки»), мягкие тени, без фона.
- Логотипы сервисов и клиентов, бейджи наград.
- Фото нет.

## Движение
Источник: `motion/motion.json` и кадры. GSAP, Lenis, Lottie не найдены — CSS-анимации и transitions, 4 canvas.

- **Hero-объект (при загрузке/входе):** части фигуры собираются по очереди — свечения и щит 500 мс `ease-in-out`, центральная часть 700 мс (задержка 100), верхняя часть с задержкой 500; иконки по кругу меняют фон и фильтр (500 мс, `cubic-bezier(0.4, 0, 0.2, 1)`) — синяя подсветка переходит между «таблетками». По ручной записи иконки по орбите не вращаются: стоят на месте, а меняется их состояние — чёрные → светлые «стеклянные» → часть загорается синим, в центре щит тоже становится синим. Похоже на цикл «найдено → проверено → защищено».
- **Заголовок (сам по себе, цикл):** фразы появляются каскадом 600 мс с шагом 150 мс (`ease-out`), подзаголовок 500 мс (450). Дальше активная фраза переключается по кругу примерно раз в 2 с (по записи: Every Agent → Every Secret → Every Identity), смена цвета 300 мс.
- **«What Clutch Secures» (sticky, по записи 14–18 с):** слева закреплена панель-схема Identity Lineage (Person → Agent → Tools → Identities → Resources с конкретными примерами: «Sarah Chen, Senior Engineer», «github-mcp-server»), справа прокручиваются блоки Identities / AI Agents / Secrets; содержимое панели меняется под активный блок.
- **Триада объектов (вход в экран):** Human → AI Agents → Non-Human появляются слева направо — 500 мс `ease-out`, задержки 0 / 550 / 1100 мс, пилюли-связи 200 / 750 / 1300 мс. На мобильном шаг короче (0 / 300 / 600).
- **Шапка:** fixed, при скролле прячется/появляется (top и opacity 300 мс).
- **Отзывы:** карточки появляются 350 мс `ease-out`, вкладки-логотипы переключают отзыв.
- **Веер интеграций (вход в экран):** 35 логотипов проявляются (opacity 1000 мс), три световые линии — 600 мс `ease-in-out`.
- Scrub нет; закреплён только блок со схемой в «What Clutch Secures».
- **Мобильный (по записи):** hero со сменой фраз и диском, логотипы сеткой 2×2, триада объектов вертикально со стрелками-пилюлями, схема Lineage, таблицы-фрагменты UI стопкой; анимации те же, но без sticky.

## Сценарий страницы

2. Логотипы клиентов.
3. «They Exist Everywhere. They're Managed Nowhere.» — триада объектов (проблема).
4. «Introducing Clutch — The Identity Security Platform for the AI Era» — Identity Lineage.
5. «What Clutch Secures» — Identities / AI Agents / Secrets.
6. «Secure Identities. Agents. Secrets.» — вкладки.
7. «The Clutch Approach», «Instant Setup, Immediate Impact» — веер интеграций.
8. Отзыв, награды, футер.

## Что берём / что нельзя копировать
- Берём: невидимое (учётки, агенты) как осязаемые 3D-объекты; заголовок с переходящей подсветкой фраз; триаду объектов со связями-пилюлями для объяснения проблемы; веер логотипов как «мгновенная интеграция»; страницу-лист в рамке тонких линий.
- Не копируем: чёрные глянцевые фишки и диск, синий акцент на белом, тексты.
