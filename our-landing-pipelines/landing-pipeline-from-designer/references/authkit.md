# Паспорт референса: AuthKit (WorkOS)

- **URL:** https://www.authkit.com/
- **Направление:** технологичный, премиальный (тёмный «космос» с прожекторами, Apple-like подача dev-продукта)
- **Для каких продуктов подходит:** инфраструктура и dev-tools, безопасность и авторизация, API-продукты; запуск одного компонента/фичи как события
- **Скриншоты:** `references/shots/authkit/shots/2026-10-05_20-20-43.png` (снят вручную, 1860 px), `0-desktop.png` (досняла `research.mjs` 06.10.2026). На обоих нижняя половина страницы пустая — секции рисуются только при входе в экран; полную картину дают кадры `motion/frames/desktop` и листы `motion/webm-frames/desktop`. Мобильного полного скриншота нет — есть кадры `motion/frames/mobile`. Тексты — `pages.json` (собран 06.10.2026), движение — `motion/`.

## Центральная идея
«The world's best login box»: один UI-компонент — окно входа — подан как ювелирное изделие на сцене. Прожектор сверху, три окна входа веером, вокруг — тонкая сетка и звёздная пыль.

## Сигнатурный приём
- Прожектор (spotlight) сверху над заголовком — мягкий конус света, который медленно «дышит».
- Окна входа веером (три бренда: Blamer, SuperApp, Clamer) — продукт = сам компонент, свёрстанный кодом.
- Схемы-«микросхемы»: архитектура (AuthKit → WorkOS → ваша база/приложение/Events API) как плата с дорожками и чипами.
- Бегущий свет по обводке кнопок и карточек.

## Композиция и сетка
- Узкая центральная колонка ≈720 px, всё по центру; тонкие линии сетки с крестиками на пересечениях (как чертёж).
- Hero: «Introducing» → огромный «AuthKit» → подзаголовок → окна входа → переключатель светлой/тёмной темы → ряд из 6 иконок методов входа с соединительными линиями.
- Секции: мелкий ярлык с линиями по бокам → заголовок в 2 строки → короткий абзац → большая иллюстрация-схема.
- «Your brand. Your style.» — окно входа в центре, вокруг панели настроек (цвет, радиус, логотип).
- «Built on Radix» — код + 3D-фигуры; «Designed for developers. Built for the enterprise.» — плитки функций безопасности; «The one platform…» — схема; отзывы; «Start building today» + 2 CTA-карточки.

## Типографика
- Гротеск с мягкими формами (по виду Söhne / GT Walsheim-подобный), заголовки ≈32 px regular, «AuthKit» ≈110 px с голубоватым градиентом. Аналог с кириллицей: **Manrope** или **Inter**.
- Мелкий текст ≈13 px, серо-голубой.

## Цвет
- Глубокий тёмно-синий почти чёрный (≈#060814) с холодными голубыми бликами.
- Текст — бледно-голубой (≈#C9D6F5) с градиентом в крупных заголовках.
- Акцент — фиолетово-синяя кнопка «Continue» (≈#6E56F8) внутри окна входа.
- Свет — голубовато-фиолетовые прожекторы и свечения.

## Изображения
- Фото нет. Всё — UI кодом (окна входа, панели настроек) и стилизованные схемы-платы.
- 3D-формы (сферы/цилиндры) в разделе Radix, иконки методов входа как маленькие стеклянные кнопки.
- Видео `authkit.webm` (автозапуск) в рамке-«outline box».

## Движение
Источник: `motion/motion.json` и кадры. GSAP, Lenis, Lottie не найдены — CSS-анимации и transitions, 4 canvas.

- **Вступление hero (при загрузке):** линии сетки проявляются 3000 мс (`ease`); прожекторы — opacity 1500 мс с разбросом задержек 300–2100 мс; шапка опускается (transform 1500 мс); окна входа «приезжают» 2500 мс с задержкой ≈1800 мс — центральное `cubic-bezier(0.33, 1, 0.68, 1)` (easeOutCubic), боковые `cubic-bezier(0.65, 0, 0.35, 1)` (easeInOutCubic) — веер раскрывается.
- **Прожектор (сам по себе):** opacity 6000 мс и scale 8500 мс бесконечно — медленное «дыхание» света.
- **Иконки методов входа (сам по себе):** блик пробегает по иконкам по очереди — 1500 мс, шаг 1200 мс (0 → 6000 мс), разделители-линии проявляются маской.
- **Бегущий свет:** по обводке кнопок `line-anim` 16 с + «небо» 2 с; по карточкам 12 с с пульсацией 3 с; по CTA-карточкам 6 с.
- **Схемы (сами по себе):** дорожки и лампочки «работают» — вращение 4–5 с, линии 10–30 с, радар 40 с, точки 40 с, «дыхание» 5 с.
- **Сценки безопасности (вход в экран):** радар находит утёкший пароль (transform 3000 мс), рамка подсвечивается (800 мс), полоса силы пароля растёт (width 1000 мс), роль переключается ADMIN → EDITOR (текст «перебирается»: «-I-W•×»), поле MFA заполняется. Easing `cubic-bezier(0.6, 0.6, 0, 1)` — фирменный «рывок с мягкой посадкой».
- **Кнопка в окне** «нажимается» сама (300 мс с задержкой 1500).
- Закреплённых секций и scrub нет — всё при загрузке, при входе в экран или по кругу.

## Что берём / что нельзя копировать
- Берём: подачу одного компонента как драгоценности под прожектором; веер вариантов компонента; живые мини-сценки вместо иконок фич (радар, перебор ролей, заполнение MFA); бегущий свет по обводке; сетку-чертёж с крестиками.
- Не копируем: тёмно-синий «космос» с голубыми прожекторами, схему-плату, окна входа брендов, тексты. Синие градиенты «про технологии» запрещены правилами проекта — брать приём, не палитру.

## Ручные доработки
Ручная запись экрана не удалась (06.10.2026) — решено ориентироваться на автоматические видео `motion/desktop.webm` и `motion/mobile.webm`. Из них вынуты листы-сетки кадров: `motion/webm-frames/desktop` и `motion/webm-frames/mobile` (кадр каждые 2 с, время подписано).
- **Пустая нижняя половина скриншотов закрыта видео:** на листах видна вся страница по порядку — окна входа, схема-плата, «Your brand. Your style.» с панелями настроек, «Built on Radix» с 3D-фигурами (квадрат, сфера, четверть круга) и кодом, сценки безопасности, «The one platform», отзывы, «Start building today».
- **Подтверждено:** секции появляются при входе в экран, pin и scrub нет — совпадает с разделом «Движение».
- **Мобильный (по `mobile.webm`, листы `webm-frames/mobile`):** первые ≈30 с записи — тёмное вступление с сеткой и прожектором, дальше вся страница одной колонкой по центру. Методы входа — 2 ряда по 3 подписи с кружками-узлами; заголовки секций крупные (≈34 px, 3–4 строки), ярлык с линиями по бокам сохраняется. Схема-плата сжата до одного светящегося узла; «Built on Radix» — 3D-фигуры и код обрезаны краем экрана; плитки безопасности (Leaked password, RBAC, Password strength…) стопкой во всю ширину, живые сценки внутри работают так же, как на десктопе.
