# Паспорт референса: Notion

- **URL:** https://www.notion.com/
- **Направление:** иллюстративный, дружелюбный (ч/б рисованные персонажи + чистый продуктовый UI)
- **Для каких продуктов подходит:** рабочие пространства, продуктивность, ИИ-ассистенты для команд; когда интерфейс плотный и его нужно «очеловечить» лёгкой графикой
- **Скриншоты:** `references/shots/notion/shots/0-desktop.png`, `0-mobile.png`; тексты — `pages.json`; движение — `motion/` (`motion.json`, кадры, `desktop.webm`, `mobile.webm`)
- **Важно:** на 06.10.2026 иллюстраций на главной стало меньше, чем было исторически: персонажи живут только вокруг окна продукта в hero и в мелких иконках сценариев. Приём узнаваемый, но «тонкий».

## Центральная идея
«Where teams and agents ___ together»: продукт показан как живое окно рабочего пространства, а рядом — нарисованные от руки человечки (с ноутбуком, с лампочкой, «облачко мысли»), которые и есть «команда и агенты». Строгий UI + тёплая рисованная линия.

## Сигнатурный приём
- Ч/б иллюстрации тонкой неровной линией, «как в блокноте»: человечки выглядывают из-за окна приложения, сидят на его краю, парят над ним.
- Слово-ротатор в H1 в цветной пилюле с точкой: Think (голубая) → Create (оранжевая) → Build (жёлтая) — у каждого глагола свой цвет.
- Мелкие цветные «агенты»-аватары внутри UI (кружки с иконками) — продолжение иллюстративного языка внутри интерфейса.

## Композиция и сетка
- Контейнер ≈1100 px, hero по центру: H1 в 2 строки, подзаголовок, 2 кнопки, большое окно продукта с персонажами по краям, лента логотипов прямо под окном.
- «AI where your team works» — заголовок слева, ниже 3 карточки-сценария (Capture knowledge / Find answers / Automate busywork) с фрагментами UI.
- «See what Notion can do» — ряд из 5 иконок-сценариев с цветными кружками.
- Отзывы — 3 фото-карточки, тонированные в один цвет (красный, синий, жёлтый) с цитатой поверх.
- Бегущая строка с цифрами, финальный CTA «Get started today.», футер с цитатой Маклюэна.
- Плотность низкая, много белого.

## Типографика
- Собственный гротеск Notion (по виду близко к Inter Display / SF Pro Display), H1 ≈64 px, жирный, плотный трекинг, межстрочный ≈1.05. Аналог с кириллицей: **Inter** (SemiBold/Bold).
- Текст ≈16 px, серый.
- Цитаты в отзывах и футере — сериф (по виду Lyon / Tiempos). Аналог: **PT Serif**.

## Цвет
- Белый фон, почти чёрный текст, иллюстрации строго ч/б.
- Акцент — синий (≈#0B6BCB) у основной кнопки.
- Цвет только точечный: пилюли глаголов (голубой, оранжевый, жёлтый), кружки-агенты в UI, монохромные тонировки фото отзывов (красный ≈#C8302A, синий ≈#2C5BB4, горчичный ≈#C79A1C).

## Изображения
- Ч/б рисованные персонажи (авторский стиль, линия разной толщины, минимум заливки) — главный иллюстративный приём.
- Скриншоты/видео продукта (`web-homepage-hero-1920x1200_final.mp4` — зацикленное видео окна Notion).
- Фото людей в отзывах, перекрашенные в один цвет (дуотон).

## Движение
Источник: `motion/motion.json` и кадры. GSAP, Lenis, Lottie не найдены.

- **Слово-ротатор в H1 (само по себе):** глагол в пилюле меняется по кругу Think → Create → Build…, вместе с ним меняется цвет пилюли; ширина пилюли подстраивается под слово — width 300 мс, `cubic-bezier(0.86, 0, 0.07, 1)` (easeInOutQuint, резкий).
- **Окно продукта в hero (видео, само по себе):** зацикленное видео — в окне появляются задачи, курсоры и аватары агентов, иллюстрированные персонажи вокруг окна статичны; есть кнопка паузы.
- **Шапка:** sticky, при скролле появляется тень — CSS scroll-driven (`navShadowScrolled`, длительность `auto`).
- **Логотипы:** при скролле закреплённая полоса логотипов появляется (`revealStickyBar`, scroll-driven); на мобильном — лента логотипов `marqueePolygon` 115 с.
- **Цифры:** бегущая строка 60 с, linear.
- Карточки сценариев с видео/UI внутри меняются сами (кадры y 450–900 движутся); pin-сцен и scrub нет.

## Сценарий страницы
1. Hero: «Where teams and agents Create together.» + окно продукта с персонажами — кульминация образа.
2. Логотипы клиентов.
3. «AI where your team works» — 3 сценария.
4. «See what Notion can do» — 5 сценариев-иконок.
5. «Trusted by teams that ship» — дуотон-отзывы, цифры.
6. «Get started today.», футер.

## Что берём / что нельзя копировать
- Берём: связку «строгий UI + рисованные ч/б персонажи вокруг него»; слово-ротатор с цветом под каждый глагол; дуотон-фото в отзывах; персонажей как «людей продукта» без фото.
- Не копируем: стиль конкретных персонажей Notion (авторский), их шрифт, тексты. Свой иллюстративный язык генерируем.
