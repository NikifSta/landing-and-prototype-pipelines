# Библиотека референсов

Цель — разные направления, чтобы пользователь выбирал стиль, а 100 лендингов не были похожи. У каждого референса есть паспорт `references/<slug>.md` (по шаблону `_passport-template.md`) и материалы в `references/shots/<slug>/`: скриншоты, тексты, движение (`motion/`, ручные записи — `motion/manual-frames/`).

Критерии отбора: страница SaaS; есть режиссура (сценарий, кульминация); продукт показан убедительно; хотя бы один сильный приём движения; работает на телефоне.

## По направлениям

| Направление | Референс | Паспорт | Сигнатурный приём | Сильное движение |
|---|---|---|---|---|
| Дружелюбный, тёплый | Structured | `structured-app.md` | жизнь человека → лента дня, устройства, слово-ротатор в H1 | видео в hero с наездом контента, pin-сцена шагов |
| Дружелюбный, тёплый | Pop Site | `pop.md` | поле «займи имя» сквозным CTA, веер телефонов с персонажами | каскад появления от центра |
| Технологичный минимал | Linear | `linear.md` | интерфейс как иллюстрация на почти чёрном | вступление hero с blur, живые чаты агентов |
| Технологичный минимал | Paper | `paper.md` | сквозная демо-история в одном окне, терминал агента | агент печатает и строит экран |
| Технологичный минимал | Monologue | `monologue.md` | сцены «продукт делает работу» с тостом-итогом, моно + сериф | pin-меню сценариев, подсветка манифеста по скроллу |
| Технологичный, премиальный | AuthKit | `authkit.md` | один компонент под прожектором, веер вариантов | живые мини-сценки безопасности, бегущий свет |
| Премиальный | Superhuman | `superhuman.md` | человек в центре, окна UI парят вокруг | parallax окон, sticky-вкладки продуктов |
| Премиальный | Mercury | `mercury.md` | сюрреалистичная тихая сцена (стол на горе) | pin + видео-scrub «влёт в экран ноутбука» |
| Премиальный, предметный | FLITE | `flite.md` | продукт как драгоценность на нейтральном поле | пословное появление H1, sticky-карточка покупки |
| Премиальный, климат/наука | Alethia | `alethia.md` | левитирующий «образец природы», природа ↔ прибор | pin + scrub пролёт сквозь сцену, перевод фокуса |
| Деловой B2B | Pitch | `pitch.md` | страница как презентация, мозаика отзывов | манифест по словам, счётчики-барабаны, стопка шагов |
| Деловой B2B | Clutch | `clutch.md` | невидимое как 3D-объекты, триада со связями | переходящая подсветка фраз, sticky-схема |
| Технологичный, тёплый B2B | Weave | `weaveos.md` | тактильный маскот, физическая метафора процесса | ленты через катушку, шапка-пилюля |
| Редакционный, журнальный | Streamtime | `streamtime.md` | коллаж «фото людей + бумажные фигуры», вордмарк | вордмарк превращается при скролле, parallax коллажа |
| Редакционный, ИИ без клише | Granola | `granola.md` | бумажный блокнот поверх природы, сериф | CSS scroll-driven: pin демо, заметка пишется сама |
| Редакционный, креативный ИИ | Melius | `melius.md` | вкладка → промпт печатается → результат + граф нод | pin-сцена индустрий |
| Игривый, яркий | GGaide | `ggaide.md` | один цвет + один персонаж + огромный шрифт | scramble заголовков, плавающая навигация |
| Игривый, редакционный | Control (cntrl) | `cntrl.md` | страница как демо продукта, антиква + гротеск | текст по синусоиде, шейдер в футере |
| Иллюстративный | Notion | `notion.md` | ч/б рисованные персонажи вокруг строгого UI | слово-ротатор с цветом под глагол |

| Иллюстративный, игривый | The Mainstays | `mainstays.md` | фуд-фото + однолинейные руки-иллюстрации, финал-паттерн | волнистые края, карусель банок |
| Иллюстративный, коллаж | Trevor Noah | `trevornoah.md` | фото-«стикеры» с обводкой + 3D-предметы + рваная бумага | WebGL hero, пружинящие появления |

## Заметки
- Не SaaS, берём только визуал и приёмы подачи: FLITE (велоруль), GGaide (конференция), The Playa (iGaming), Alethia (климат-измерения), The Mainstays (соусы), Trevor Noah (личный сайт).
