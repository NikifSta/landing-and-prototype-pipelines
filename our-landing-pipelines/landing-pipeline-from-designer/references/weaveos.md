# Паспорт референса: Weave

- **URL:** https://weaveos.com/
- **Направление:** технологичный, дружелюбный (инженерная аналитика + милый 3D-маскот)
- **Для каких продуктов подходит:** B2B SaaS для инженеров, аналитика и метрики, ИИ-инфраструктура; когда сухой продукт нужно сделать тёплым
- **Скриншоты:** `references/shots/weaveos/shots/0-desktop.png`, `0-mobile.png`; тексты — `pages.json`; движение — `motion/`

## Центральная идея
«Turn your software team into a software factory»: серьёзная аналитика инженерной работы подана через тактильный мир — вязаный оранжевый клубок-маскот Wooly, деревянные иконки, «конвейерные ленты» с промптами.

## Сигнатурный приём
- Маскот Wooly — вязаный клубок с глазами и ножками, сидит на табурете; в разделе об агенте — целая «процессия» клубков с разными предметами.
- Иконки фич как деревянные/фанерные объекты (графики, монеты, скобки {}, AI-кубики), парят вокруг маскота.
- Роутер промптов как физическая метафора: ленты-ремни с текстом промптов проходят через «катушку» с логотипом и уходят к разным моделям.
- Тёплый бежевый мир + один яркий оранжевый.

## Композиция и сетка
- Контейнер ≈1100 px, hero центрирован (маскот → H1 → 2 кнопки), под ним плашка «Trusted by…» с лентой логотипов и 4 цифрами в сетке.
- Секции фич — карточки на светло-сером фоне: слева ярлык (оранжевый) + заголовок + текст, справа или снизу — UI (таблица, полосы затрат, граф источников данных).
- Шаги роутера: терминал слева, 3 шага справа.
- Агент Wooly: центрированный блок + окно чата «What do you want to know?».
- Кейс, цифры (+19%, 14 days), compliance-плитки (GDPR, HIPAA, SOC2…), тёмный футер с гигантским вордмарком «weave».

## Типографика
- Заголовки — мягкий гротеск полужирный, тёмно-бордовый (≈#4A1020); по виду близко к Söhne / Untitled Sans. Аналог с кириллицей: **Golos Text** или **Inter Tight**.
- H1 ≈40 px; ярлыки секций — мелкие оранжевые.
- Технические подписи и терминал — моноширинный. Аналог: **JetBrains Mono**.

## Цвет
- Тёплый светло-бежевый фон (≈#F4F1EE), карточки чуть темнее.
- Текст — тёмно-бордовый вместо чёрного.
- Акцент — насыщенный оранжево-красный (≈#F04A23): кнопки, клубок, ленты, полосы в графиках.
- Тёмный футер (≈#1A1A1A).

## Изображения
- 3D-рендеры: вязаный клубок (фактура пряжи), фанерные иконки, катушка с лентами — мягкий студийный свет, без фона.
- UI — кодом: таблица инженеров, распределение затрат по моделям, граф «commits / tokens / pull requests / reviews / deploys».

## Движение
Источник: `motion/motion.json` и кадры. GSAP, Lenis, Lottie не найдены; 2 canvas на десктопе (1 на мобильном).

- **Маскот (при загрузке):** `wooly-center-in` 1000 мс с задержкой 100 мс — клубок «приходит» в центр. Деревянные иконки вокруг двигаются (кадры y=0 меняются сами) — парят по кругу; характер движения проверить вживую.
- **Шапка (при скролле):** после ≈400 px шапка превращается в плавающую пилюлю — отступы, скругления, тень, фон за 500 мс, `cubic-bezier(0.16, 1, 0.3, 1)` (easeOutExpo); строка «New: Weave Research» схлопывается (grid-rows 500 мс, opacity 280 мс).
- **Ленты логотипов:** клиенты — 26 с на цикл; бегущая строка в блоке Wooly — 40 с, linear.
- **Роутер промптов (сам по себе, canvas):** ленты с текстами промптов непрерывно протягиваются через катушку и меняют цвет (чёрная → оранжевая) после «маршрутизации». Блок закреплён (`sticky`, top 70 px, на ≈1960 px), пока справа идут шаги «Get your router key / Run one command / Work as usual».
- **Граф источников данных** (y 876–1779 движется сам) — линии/узлы анимированы на canvas.
- **Процессия клубков в разделе агента** и чат — кадры y 4900–5800 меняются сами; что именно анимируется — проверить вживую.
- Появления блоков при входе в экран в данных нет — секции, похоже, статичны.

## Сценарий страницы
1. Hero: маскот на табурете, «Turn your software team into a software factory», 2 кнопки.
2. Логотипы + цифры (2M+ PR, 25k+ инженеров, 50+ инструментов, SOC2).
3. Engineering intelligence — граф источников.
4. «Turn AI adoption into engineering output» — таблица.
5. Token intelligence — затраты по моделям.
6. Coding Agent Router — ленты через катушку (кульминация).
7. Agent Wooly — процессия клубков + чат.
8. Кейс клиента с цифрами, compliance, футер с вордмарком.

## Что берём / что нельзя копировать
- Берём: тактильного маскота для «сухого» B2B; физическую метафору процесса (ленты через катушку) вместо абстрактной схемы; тёмно-бордовый текст вместо чёрного для тепла; превращение шапки в плавающую пилюлю.
- Не копируем: вязаный клубок, оранжево-бежевую палитру, катушку с лентами буквально, тексты.
