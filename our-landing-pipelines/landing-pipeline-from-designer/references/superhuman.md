# Паспорт референса: Superhuman

- **URL:** https://superhuman.com/
- **Направление:** премиальный, дружелюбный (AI-suite: живой портрет человека + плавающие окна интерфейса)
- **Для каких продуктов подходит:** ИИ-ассистенты и продуктивность, наборы продуктов (suite), B2B SaaS с массовым B2C-входом
- **Скриншоты:** `references/shots/superhuman/shots/0-desktop.png` (снят вручную, 1841 px). Мобильного полного скриншота нет; мобильный вид — по ручной записи `motion/Вручную. Superhuman_ Mobile.mp4` и кадрам `motion/manual-frames/mobile`. Тексты в `pages.json` пустые — заголовки взяты из HTML 06.10.2026. Движение — ручные записи `motion/Вручную. Superhuman_ Desktop.mp4` / `Mobile.mp4` + кадры `motion/manual-frames/`.
- **Версия-референс:** ориентируемся на ручные записи 06.10.2026 — версия «Superpowers, everywhere you work» (портрет в профиль на небе, вкладки suite Mail / Grammarly / Docs / Go). Портрет на сайте меняется (на скриншоте — женщина, на записи — мужчина в оранжевой шапке), приём тот же. Автозапись `motion.json` поймала другой вариант hero (карусель продуктов Go / Mail / Docs) — похоже, сайт показывает разные версии (A/B); он описан ниже как дополнительный.

## Центральная идея
«Superpowers, everywhere you work»: ИИ не в отдельном окне, а поверх любой работы. Человек в центре кадра, вокруг него парят окна чата, документа, почты и календаря — ассистент «живёт» рядом с ним.

## Сигнатурный приём
- Hero: профиль человека на сиренево-синем закатном небе, вокруг полупрозрачные стеклянные окна — чат с ассистентом («book it for monday»), документ с подсвеченными правками, вертикальная панель иконок, подсказка «Tailor this language for executives», список писем (Important / Calendar / Docs).
- Окна разъезжаются при скролле с разной скоростью — глубина сцены (см. «Движение»).
- Подчёркивания-«агенты» в тексте: ИИ подчёркивает фразы прямо в документе.
- Огромный вордмарк «SUPERHUMAN» в футере, тёмно-винный фон.

## Композиция и сетка
- Контейнер ≈1100 px, hero центрирован, дальше — 2 колонки и карточки.
- Логотипы клиентов в ряд ячеек с тонкими разделителями.
- Suite: вкладки Mail / Grammarly / Docs / Go закреплены вверху секции; для каждого продукта блок «ярлык → заголовок в 2 строки → текст → Learn more → список преимуществ» слева и картинка-градиент с UI справа.
- «Becoming Superhuman» — тёмно-зелёный блок 50/50 (коллаж с женщиной у экрана + манифест), финальный CTA на градиенте «AI that works everywhere you work», футер.
- Плотность средняя, много светлого бежевого.

## Типографика
- Гротеск с мягкими формами (по виду близко к Söhne / Inter Display), заголовки regular ≈36–48 px, H1 ≈56 px белым.
- Аналог с кириллицей: **Inter** (Regular/Medium) или **Manrope**.
- Мелкий текст ≈14 px.

## Цвет
- Светлый тёплый бежевый (≈#F5F3EF) как основной фон.
- Hero — сиренево-синее небо с розовыми облаками; тёмно-зелёный (≈#0F3B35) в «Becoming Superhuman»; винный (≈#3D1A22) футер.
- Акцент — фиолетовый (≈#6C47FF) у кнопок; градиент сиреневый → голубой → фиолетовый в финальном CTA.

## Изображения
- Фото человека крупным планом в профиль (тёплый свет, небо) — эмоциональный якорь.
- Стеклянные окна UI свёрстаны кодом.
- Карточки suite — UI на мягких градиентных подложках (небо, зелень, сирень).
- Коллаж «Becoming Superhuman»: силуэт женщины перед цветными экранами.

## Движение
Источники: ручные записи экрана (кадры `motion/manual-frames/`, время «N с» — время записи) и `motion/motion.json`. GSAP, Lenis, Lottie, canvas не найдены.

- **Hero-окна (parallax по скроллу, 3–6 с записи):** портрет и небо уезжают медленно, стеклянные окна — быстрее и с разной скоростью: чат слева и документ справа поднимаются, снизу въезжает окно со списком писем (Important / Calendar / Docs) и плашка «Scheduled 15 minutes…». Заголовок уходит вверх вместе с контентом. Слои разной глубины → ощущение пространства вокруг человека.
- **Звёздочки-искры** у кнопки «Get Superhuman» мерцают (кадры 0–3 с меняются на месте).
- **Логотипы клиентов** — статичный ряд (на записи не движутся).
- **Suite (sticky):** вкладки Mail / Grammarly / Docs / Go закреплены вверху секции (7–10 с), блоки продуктов прокручиваются под ними; активная вкладка подсвечивается по мере прокрутки.
- **«Becoming Superhuman»** — обычный поток, коллаж статичный.
- **Шапка** — sticky.
- **Мобильный (по записи):** hero в одну колонку (заголовок, кнопка, портрет без окон), дальше логотипы сеткой 3×2, suite стопкой, тёмно-зелёный блок, футер-список; заметных анимаций нет.
- **Альтернативная версия hero (из автозаписи):** карусель продуктов — полоса прогресса заполняется 10 000 мс linear → слайд сменяется растворением (`carousel-slide-dissolve-in`, 500 мс), видео автозапуск.

**Перевод в наш стек (GSAP):** hero из слоёв — фон-небо, портрет, 3–4 окна UI кодом; ScrollTrigger scrub с разными `yPercent` для каждого слоя (портрет −10%, окна −30…−60%), новое окно въезжает снизу. Sticky-вкладки секции продуктов с подсветкой активной по ScrollTrigger.

## Сценарий страницы
1. Анонс «Looking for Superhuman Mail?», шапка.
2. Hero «Superpowers, everywhere you work» + Get Superhuman + портрет с окнами (кульминация).
3. Логотипы клиентов.
4. «Your Superhuman suite» — Mail, Grammarly, Docs, Go.
5. «Becoming Superhuman» — манифест.
6. «AI that works everywhere you work» — CTA, футер с вордмарком.

## Что берём / что нельзя копировать
- Берём: человека в центре кадра и интерфейс, парящий вокруг него стеклянными окнами (ИИ «рядом», а не вместо); parallax слоёв окон по скроллу; sticky-вкладки для набора продуктов; подчёркивания-подсказки прямо в тексте документа; смену цветных фонов секций.
- Не копируем: сиренево-синее небо и фиолетовые градиенты (синие градиенты «про технологии» запрещены правилами проекта), портрет, вордмарк, тексты.
