# landing — плагин для Claude Code: лендинги для гипотез новых продуктов

Вы описываете гипотезу продукта в двух предложениях и отвечаете на два вопроса про вкус. Плагин проходит **11 этапов** и собирает лендинг: со сценарием, брендом, интерфейсами продукта, сгенерированными картинками и анимацией. Каждый следующий лендинг отличается от прошлых: вид страницы определяет не один сайт-образец, а **рецепт** (язык, настроение, подпись движения и композиция каждого блока из каталога на 280+ блоков), а реестр прошлых страниц не даёт им повторяться.

> **Быстрые ссылки:** [INSTALL.md](INSTALL.md) — установка по шагам (распаковать папку, открыть её в приложении Claude, команда `/run --auto`); [GUIDE.md](GUIDE.md) — как сделать лендинг и вносить правки.

## Что нужно
| Что | Зачем |
|---|---|
| **Claude Code** (приложение Claude → вкладка Code, либо терминал `claude`) | запускает плагин |
| **Node.js 20 или новее** (`node -v`) | скрипты плагина |
| **Git** | скачать плагин |
| **Генерация картинок и видео** | изображения — Astra (`gpt-6-astra`) через Codex под входом ChatGPT, видео — Seedance 2.5 в Dreamina через Chrome навигатора. Без них блоки заменяются графикой кодом |

Установлен в проект hypothesis-tester (`dev/pipelines/landing-pipeline-from-designer/`, установка — [INSTALL.md](INSTALL.md)) и работает на его Linux-сервере. Проверка: `node -v` (v20+), `codex login status`.

## Установка (один раз)
```bash
git clone <адрес репозитория> landing-pipeline
cd landing-pipeline
npm run setup
```
`npm run setup` ставит зависимости и браузер Chromium для скриншотов. Затем создайте файл с ключами:
```bash
cp .env.example .env
```
В `.env` уже стоят генераторы: `MEDIA_IMAGE_GENERATOR=astra-via-codex` и `MEDIA_VIDEO_GENERATOR=seedance-2-5-in-dreamina` (пусто — без видео). Ключей в нём нет; файл в `.gitignore`.

## Первый запуск
1. Создайте **пустую рабочую папку** для своих лендингов (не внутри `landing-pipeline`), например `landing-work`.
2. Запустите в ней Claude Code, подключив плагин:
   ```bash
   cd landing-work
   claude --plugin-dir /полный/путь/к/landing-pipeline
   ```
   В приложении Claude (вкладка Code) откройте папку `landing-work` и добавьте плагин из папки `landing-pipeline` в настройках плагинов; в терминале достаточно команды выше.
3. Напишите:
   ```
   /run Приложение для родителей: подбирает репетитора и показывает прогресс ребёнка после каждого занятия
   ```
   Достаточно двух-трёх предложений: что делает продукт, для кого, какую проблему решает. Аналоги искать не нужно: плагин найдёт их сам.

## Что будет происходить
| # | Этап | Что получите |
|---|---|---|
| 1 | `intake` | черновик гипотезы, аналоги, **доска вкуса**: 8 разных сайтов, вы отвечаете, что нравится и что нет |
| 2 | `research` | разбор аналога по коду страницы и скриншотам |
| 3 | `story` | сценарий и секции страницы, **три варианта рецепта на выбор** (A, B, C) |
| 4 | `demo-story` | сквозная вымышленная история с данными для всех экранов |
| 5 | `brand` | название, логотип, палитра, шрифты |
| 6 | `art-direction` | дизайн-план по рецепту и черновик первого экрана |
| 7 | `media` | сгенерированные изображения (спросит согласие на стоимость) |
| 8 | `ui` | интерфейсы продукта и анимированные сцены на HTML, поверх снимков |
| 9 | `build` | собранная страница `site/index.html` |
| 10 | `qa` | автоматическая проверка и просмотр по кадрам |
| 11 | `publish` | ссылка на страницу запуска my.holdi.ai; при тестовых значениях в пошаговом режиме — после вашего подтверждения |

**Вас спросят в трёх местах:** доска вкуса (этап 1), выбор варианта A/B/C (этап 3) и данные, которых нельзя придумать (цены, сроки, гарантии). На вопрос про данные можно ответить «позже»: страница соберётся с заглушками, а публикация подождёт, пока вы не подтвердите значения. Полный прогон занимает примерно 1,5–2,5 часа; изображения — в подписке ChatGPT.

### Режим «ответил один раз и ушёл»
```
/run --auto Приложение для общего бюджета пары. Можно картинки и 3D, видео не нужно, тестовые цены разрешены.
```
В этом режиме все вопросы задаются в самом начале (одним сообщением, недостающее заполняется разумными допущениями). Дальше референс, рецепт и направление выбирает плагин, каждое решение с причиной записывается в `projects/<проект>/decisions.md`, время этапов — в `timings.md`. Тестовые значения на странице не помечаются: их список приходит в чат и лежит в `open-questions.md`; страница выкладывается на страницу запуска сразу после проверки, без отдельного вопроса. Если подходит лимит Claude, прогон останавливается, сохраняет состояние в `progress.md` и продолжается командой `/run <папка проекта>` после сброса.

### Видео (по необходимости)
Видео генерируется только если оно объясняет продукт и подходит теме (нужен `MEDIA_VIDEO_GENERATOR=seedance-2-5-in-dreamina` в `.env`). Это дорого (около 455 кредитов Dreamina за ролик 5 секунд в 1080P, несколько минут ожидания), поэтому стоимость называется заранее; ролики без звука, с постером на случай неудачной загрузки.

Любой этап можно запускать отдельно: `/intake`, `/research`, `/story` и так далее, продолжить прерванный проект — `/run <папка проекта>`.

## Где результат
В вашей рабочей папке: `projects/<название-проекта>/`. Главное:
- `site/index.html` — готовая страница (на компьютере — `node <папка плагина>/scripts/serve.mjs` из рабочей папки и адрес `http://localhost:5180/projects/<проект>/site/index.html`; с телефона — ссылка страницы запуска);
- `checklist.md` — на каком этапе остановились;
- `open-questions.md` — вопросы, на которые вы ответили «позже»;
- `recipe.json` — выбранный рецепт; `projects/_registry.json` — реестр всех ваших страниц.

## Если что-то не работает
| Симптом | Что сделать |
|---|---|
| `Executable doesn't exist` (Chromium) | `npx playwright install chromium` из папки плагина |
| картинки не генерируются | проверьте `codex login status` («Logged in») и `MEDIA_IMAGE_GENERATOR` в `.env`; для видео — Chrome навигатора со входом в Dreamina и кредиты |
| сайт-аналог не открывается (ошибка SSL, блокировка) | плагин сам пробует архивную копию; можно задать `PROXY=http://адрес:порт` в `.env` |
| достигнут лимит Claude | подождите сброса и повторите `/run <папка проекта>`: прогон продолжится с первого неотмеченного этапа |

## Как устроено
- `skills/` — этапы и оркестратор `run`; тяжёлые этапы выполняются вложенными агентами с чистым контекстом, чтобы дизайн не страдал от длинной переписки.
- `references/` — паспорта референсов, лёгкие превью (`thumbs/`: первый экран, `blocks/`: полосы страницы для просмотра блоков доноров) и **каталог архетипов блоков** (`_archetypes/`: 280+ блоков, 30+ языков).
- `scripts/` — генератор рецептов (`recipe.mjs`), доска вкуса, разбор сайтов по коду, проверки контраста и верстки, сборка страницы, генерация изображений.
- `CLAUDE.md` — правила качества (запрещённые клише, анимации, типографика); каждое замечание заказчика превращается в правило.

## Ограничения (честно)
- Качество зависит от модели и от того, как долго идёт сессия: тяжёлые этапы поэтому вынесены в отдельных агентов.
- Данные страницы (имена, суммы, даты) вымышлены и помечены; цены, сроки и гарантии продукта вы подтверждаете сами.
- Сайты-аналоги за региональной блокировкой анализируются по архивной копии без анимаций.
- QR на макетах и форма заявки — оформление, не рабочие.
