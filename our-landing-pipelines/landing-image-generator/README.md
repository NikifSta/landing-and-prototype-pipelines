# Landing Image Generator

Создаёт изображения для визуальных зон лендинга по заказу этапов 2–4 [пайплайна лендинга](../premium-landing-prototype-pipeline-version-5/README.md) и первые кадры роликов для [пайплайна видео](../landing-video-generator/README.md): фотографии, иллюстрации, предметные и 3D-сцены, иконки. Сцену раскладывает на слои — чистый фон и объекты с прозрачностью, — чтобы они двигались при прокрутке; иконки и первые кадры роликов остаются цельными. Интерфейс продукта, продуктовые сцены, схемы и графики этапы собирают сами в HTML/CSS/SVG.

## Как вызывать

Одна зона — один агент с промптом [generate-landing-image.md](generate-landing-image.md). Вход описан в его разделе «Вход»: место и содержание зоны приходят из её аннотации на странице. Независимые зоны запускаются параллельно; порядок задаёт вызвавший.

## Результат

В папке результата: `<зона>.<расширение>` — цельная сцена; `<зона>-background.<расширение>` и `<зона>-layer-<объект>.png` — слои; `<зона>-layer-<объект>-green.png` — объект до вырезания; `*-prompt.md` — промпты генератору; `*-codex-answer.txt` — ответы Codex. Вызвавшему возвращается строка для поля Result.

Генератор — Astra (`gpt-6-astra`) через Codex; команда — в промпте, раздел 5. Вырезание фона — полный ffmpeg с фильтрами `chromakey` и `despill`.
