# App Prototype Factory

Промпт для Astra, создающий пять полных пайплайнов изготовления frontend-демо приложений для лендинга, и комплект актуальных исходных документов.

## Запуск создания пяти пайплайнов

Передай Astra эту папку целиком и команду:

> Выполни MASTER_PROMPT.md. Прочитай INTEGRATION_MAP.md и исходные документы, создай пять самостоятельных пайплайнов в pipelines/, проверь их через независимого субагента и сохрани полный комплект. На этом запуске создаём пайплайны; конкретное приложение будем запускать отдельно.

## Состав

- `MASTER_PROMPT.md` — полное задание на создание пяти пайплайнов.
- `INTEGRATION_MAP.md` — стыковка исследования с прежним процессом и конкретные изменения конфликтующих правил.
- `source-pipeline/` — полные неизменённые копии актуальных промптов основного процесса, общего плана, пяти UX/UI-методов и служебных документов.
- `SOURCE_MANIFEST.json` — исходные пути, версии, размеры и контрольные суммы копий.

Папка содержит задание и исходную базу. Новые пайплайны, исследование десяти сервисов и прототипы конкретного приложения появятся после соответствующих запусков.

Новый процесс: подтверждение идеи и отличий → исследование минимум десяти сервисов после входа → единое видение и подробное задание → существующая UX-цепочка → пять методов дизайна и сборки → проверенные демо и материалы для лендинга.

После начального подтверждения продуктовые вопросы и промежуточный выбор дизайна выполняются автономно по правилам мастер-промпта. Помощь с авторизацией запрашивается только при необходимости.
