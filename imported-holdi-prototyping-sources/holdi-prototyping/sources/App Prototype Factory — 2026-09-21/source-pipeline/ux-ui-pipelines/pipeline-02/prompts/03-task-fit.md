# 03 — Проверка задачами и выбор пользователя

**Исполнитель:** UX-дизайнер; отдельный reviewer; пользователь выбирает.

**Цель:** Проверить варианты задачами продукта и получить выбор пользователя.

**Входы:** C; REFERENCES.md; studies/; inputs/DATA.json.

**Действия:** Для каждого варианта проведи главную задачу: вход, поиск нужного, действие, результат. Проверь доступ к остальным задачам охвата. Сформируй полную модель сущностей, связей, маршрутов и состояний. Reviewer проверяет варианты на одинаковых задачах и выполняет визуальную сверку по PIPELINE; получает анонимные материалы без авторских оценок. Выполни предъявление и паузу по разделу «Выбор ключевого экрана пользователем» в PIPELINE.

**Выход:** MODEL.md, проверенные studies/ и выбор в RUN.md → 04; evidence/REVIEW.md → приёмка.

**Проверка и возврат:** Несовместимость с задачами верни в 02, неверный референс — в 01; модель уточни здесь. Развитие системы начинается после подтверждённого выбора.
