# 05 — Собрать приложение из системы

**Исполнитель:** frontend-исполнитель.

**Цель:** Закрыть все продуктовые сценарии без расхождения компонентов.

**Входы:** C; MODEL.md; DESIGN.md; REFERENCES.md; prototype/; inputs/DATA.json.

**Действия:** Собери остальные экраны из проверенных компонентов и правил. Реализуй локальные операции, переходы, обновление связей, адаптацию и нужные состояния. Общие исправления вноси в компонент и проверяй все места его использования. Подготовь нужные ассеты и проверь интеграцию. Актуализируй MODEL по фактическим маршрутам.

**Выход:** Законченный prototype/, актуальные MODEL.md и DESIGN.md → полная проверка.

**Проверка и возврат:** Сверь все сценарии и отсутствие отдельных расходящихся копий контролов. Системную проблему верни в 03/04; локальную интеграцию исправь здесь.
