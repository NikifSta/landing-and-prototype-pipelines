# 07 — Независимая приёмка

**Исполнитель:** новый reviewer; оркестратор передаёт результат.

**Цель:** Решить, готов ли результат к пользовательскому выбору.

**Входы:** Правила PIPELINE; inputs/; MODEL.md; REFERENCES.md; анонимные материалы визуальной сверки из evidence/; prototype/; HANDOFF.md. Авторские оценки из RUN и REVIEW скрыты до независимого заключения.

**Действия:** Самостоятельно запусти приложение, пройди задачи, проверь обязательные условия и рассмотри экраны на целевых размерах. Выполни визуальную сверку с референсами по PIPELINE. Оцени функцию, UX и визуальные критерии отдельно, подкрепи визуальные оценки парными фрагментами. После своего заключения сопоставь его с прежними замечаниями. При дефекте верни пакет автору по карте причин; повторно проверь исправленное в оставшихся раундах исправлений. Оркестратор предъявляет прошедшую версию пользователю.

**Выход:** Итог evidence/REVIEW.md, выбранный checkpoint и статус RUN.md → сравнение; prototype/, DESIGN.md, HANDOFF.md, evidence/ → пользователь и разработка.

**Проверка и возврат:** Все gates обязательны. До подтверждения пользователем статус «проверен, ожидает визуального выбора». При отказе пользователя или незакрытых дефектах после последнего раунда — «не принят» с причинами. Допустимо отклонить все варианты.
