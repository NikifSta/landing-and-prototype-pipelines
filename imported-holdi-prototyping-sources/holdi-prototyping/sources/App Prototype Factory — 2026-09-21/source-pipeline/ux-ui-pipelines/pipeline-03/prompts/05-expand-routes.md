# 05 — Расширять законченными маршрутами

**Исполнитель:** дизайнер и frontend-исполнитель.

**Цель:** Закрыть весь охват, сохранив цельность приложения.

**Входы:** C; MODEL.md; DESIGN.md; REFERENCES.md; prototype/; inputs/DATA.json.

**Действия:** Для следующего сценария дополни MODEL точными сущностями, связями, переходами и результатом. Реализуй маршрут целиком на общей системе, пройди его и проверь пересечения с готовыми маршрутами. Повторяй до полного покрытия. Переиспользуй компоненты, обновляй связанные представления. Общие изменения применяй ко всему прототипу.

**Выход:** Полные MODEL.md, prototype/ и актуальный DESIGN.md; результаты маршрутов в evidence/ → общая проверка.

**Проверка и возврат:** Каждая задача охвата имеет работающий путь. Общий конфликт системы верни в 04, неверный контракт — в 02; локальный дефект очередного маршрута исправь здесь.
