# 02 — Задать конкуренцию решений

**Исполнитель:** оркестратор.

**Цель:** Задать пять разных направлений поиска концепции ключевого экрана.

**Входы:** C; REFERENCES.md; inputs/DATA.json.

**Действия:** Возьми ключевой экран, состояние и данные из RUN_SPEC; задай общий проверяемый фрагмент маршрута на этом экране. Задай пять разных направлений исследования организации работы, композиции и визуального характера в пределах утверждённых ограничений; выбор типографики, палитры и деталей оставь каждому автору по разделу «От референсов к экрану» в PIPELINE. Каждому автору передай полные одинаковые входы, общую рубрику и его направление; конкретную концепцию он найдёт через цикл H1–H4 из PIPELINE. Условия и число раундов исправлений одинаковы; исправления всех кандидатов входят в общие раунды запуска.

**Выход:** Задания в candidates/<id>/ и общий охват в RUN.md → пять авторов и проверка.

**Проверка и возврат:** Направления решают одинаковую задачу и оставляют пространство для последовательного поиска. Дублирующие направления или неравный охват исправь здесь.
