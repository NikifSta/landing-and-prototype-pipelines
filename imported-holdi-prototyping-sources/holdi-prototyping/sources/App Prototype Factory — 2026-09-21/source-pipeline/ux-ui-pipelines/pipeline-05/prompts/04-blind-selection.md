# 04 — Слепая проверка и выбор пользователя

**Исполнитель:** оркестратор; новый независимый reviewer; пользователь выбирает.

**Цель:** Проверить кандидатов вслепую и дать пользователю выбрать ключевой экран.

**Входы:** Правила PIPELINE; inputs/; REFERENCES.md; candidates/; общий охват из RUN.md.

**Действия:** Оркестратор случайно назначает кандидатам устойчивые номера 1–5 и сохраняет закрытую карту в selection/. Reviewer получает анонимные сборки, требования и инструкции без авторов, гипотез и прежних оценок. Он проходит одинаковую задачу, выполняет визуальную сверку по PIPELINE на анонимных материалах каждого кандидата и применяет gates к охвату экрана. По результатам выполни проверку, предъявление всех вариантов и паузу по разделу выбора в PIPELINE. Зафиксируй решение пользователя с привязкой к исходникам кандидата.

**Выход:** selection/ с картой и оценками, выбор в RUN.md → 05; evidence/REVIEW.md → приёмка.

**Проверка и возврат:** Рекомендация reviewer не заменяет выбор пользователя. При запросе правок верни причины в 02/03 в пределах общих раундов; после них без принятого решения — «не принят».
