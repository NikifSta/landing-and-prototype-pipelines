# 17 — Развить модель победителя

**Исполнитель:** дизайнер/frontend-автор выбранного направления

**Вход:** USER_SELECTED из G/DESIGN_SELECTION.json, выбранные design.pdf и DESIGN.md, независимый REVIEW, P и R/inputs и REFERENCES.

**Действия**

Проверь выбор пользователя, ID метода и хеши макетов. Только для выбранной ветки создай код в R/prototype по PDF и спецификации. Допиши MODEL до всех сущностей, связей, flows и states, сохранив продуктовые факты. Зафиксируй единый принцип решения в DESIGN и его связь с референсами; дальнейшая сборка продолжает эту реализацию и сверяется с выбранным PDF.

Сохрани остальные четыре варианта целиком для сравнения. Отдельную удачную деталь другого варианта разрешено перенести лишь при совместимости с моделью/системой победителя и повторной проверке затронутого образца; произвольный гибрид пяти стилей не является итогом метода. Далее 20 проверяет переносимость, 21 закрывает все маршруты на этой системе.

**Выход и потребитель:** R/prototype, полная MODEL и начальная DESIGN → 20/21; сохранённые кандидаты → галерея.

**Готовность:** Одна выбранная модель развивается последовательно; все требования распределены по реализации.

**Возврат:** Неполная модель → здесь; несостоятельная гипотеза → 15/18/19 в оставшемся бюджете; общий компонент → 20.
