# 18 — Подготовить пять вариантов дизайна в PDF

**Исполнитель:** дизайнеры по схеме метода; для метода05 — пять независимых авторов.

**Вход:** общие задачи, UX-основа, RUN_SPEC, REFERENCES, CONTRACTS и общая PROTOTYPE_SCOPE при наличии.

**Действия**

Создай R/candidates/01…05. Каждый design.pdf покрывает задачи и структурные вопросы обоснованного набора RUN_SPEC/CONCEPTS_OVERVIEW; фиксированного количества страниц нет. Отдельное окно может быть встроенной областью, если это видно в макете и сохраняет задачу. Единственный размер общий для проекта по RUN_SPEC и EXECUTION_POLICY при наличии. Добавь необходимый шаг в том же размере, если без него нельзя оценить ключевой переход либо существенное отличие структуры; готовые страницы сохраняй.

Различай варианты композицией, размещением областей, иерархией, типографикой, плотностью и цветовыми ролями. Перекраски одной раскладки недостаточно. Содержимое должно правдоподобно показывать внешний вид и плотность; короткие примеры допустимы без дословного воспроизведения fixtures.

У каждого варианта H1–H3 — быстрые эскизы разных принципов композиции с короткой причиной отказа, допускается один общий лист. H4 — выбранное автором визуальное направление с 1–2 совместимыми референсами. Не доводи отвергнутые эскизы до качества финальных экранов.

Собери читаемый листаемый PDF, одна страница — одно окно. DESIGN.md кратко фиксирует принцип, типографический характер, цветовые роли, используемый приём референса и карту страниц; HYPOTHESES.md — ход выбора. Полные токены, все состояния компонентов и подробные тексты до USER_SELECTED не требуются.

Один раз просмотри экспорт целиком. Исправляй только существенные проблемы по правилу точности макетов в CONTRACTS; после исправления пересмотри изменённые страницы. Не запускай отдельный посимвольный или пиксельный аудит. Код приложения, библиотечные пробы и специальный просмотрщик до выбора не создаются.

**Выход и потребитель:** пять design.pdf, краткие DESIGN/HYPOTHESES, эскизы и использованные референсы → независимый визуальный просмотр19 и общая галерея.

**Готовность:** Внешний вид пяти направлений различим, структура окон понятна, главное содержание читаемо; набор достаточен для выбора.

**Возврат:** Только существенная проблема визуального направления, структуры или главной читаемости → автору общим пакетом в бюджете R. Детальную доводку выполняет выбранная ветка после USER_SELECTED.
