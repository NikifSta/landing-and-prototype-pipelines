# Сборка метапромптов — версия 3

Python 3.8+, без зависимостей и API.

**Метапромпт** — инструкция для ведущего агента: выбрать идеи, написать **промпт генерации** и провести независимое ревью. Генератор изображений получает выбранный промпт и нужные вложения.

## Быстрый запуск

```bash
python3 build_prompt.py "Общее фото; Иллюстрация; Иконки и небольшие символы" -o section_metaprompt.md
```

Это полный шаблон с незаполненными вводными. Короткие имена категорий поддерживаются:

```bash
python3 build_prompt.py фото иллюстрации иконки -o section_metaprompt.md
```

Для заполненного результата передайте JSON:

```json
{
  "categories": ["Общее фото", "Иллюстрация"],
  "product": "Название и описание",
  "audience": "Аудитория",
  "advantages": "Подтверждённые преимущества",
  "price": "Цена; либо не указана",
  "region": "Регион",
  "cta": "Целевое действие",
  "section": "Назначение, место на странице и точные тексты",
  "references": "Вложения, соответствующие области и переносимые приёмы",
  "elements": "Категория, количество, роль и соответствие референсу; без готовых сюжетов",
  "identity": "Фирменный стиль и исходники; либо не предоставлены",
  "existing_sections": "нет",
  "format": "Десктоп, 1600 × 1400, русский язык"
}
```

```bash
python3 build_prompt.py --input request.json --require-complete -o section_metaprompt.md
```

Ключи JSON прежние. `--require-complete` проверяет наличие всех полей, без него пропуски остаются в шаблоне. Количество объектов задаётся в `elements`, а не повторением категории.

Далее:
1. Передайте собранный текст и реальные вложения агенту с доступом к субагентам.
2. Агент создаёт черновик, назначает один главный визуальный центр, проводит общий тест удаления и затем запускает ревью. Каждый заметный объект должен объяснять предложение, показывать результат, подтверждать свойство, направлять к действию или продолжать айдентику. Самооценка не считается ревью.
3. Сохраните лучшую проверенную версию как `image_prompt.md`; новые файлы в папке проекта требуют разрешения пользователя.
4. Проверьте длину и передайте этот текст с нужными вложениями генератору.

```bash
python3 build_prompt.py --check-image-prompt image_prompt.md
```

Проверка считает символы Unicode, включая пробелы и переносы, а не байты. По умолчанию целевой предел — 12 000 символов; флаг `--max-chars` задаёт другой технический предел. Проверка длины не проверяет художественное качество и не запускает генерацию. Текст никогда не обрезается.

## Независимое ревью

Рецензент: `gpt-6-astra`, `reasoning_effort=xhigh`. Один неизменный чек-лист составляется из общего блока и требований выбранных модулей. Он отдельно проверяет один главный визуальный центр, тест удаления, отсутствие параллельных метафор, случайного декора и незаказанного текста. Каждый самостоятельный объект оценивается отдельно; для фотографии и иллюстрации отдельно оценивается оригинальность идеи. Итог — минимум оценок, при невыполненном обязательном пункте максимум 7.

Порог — 8/10. Максимум три ревью: исходный вариант и две доработки. При достижении порога цикл останавливается; выбирается версия с максимальной оценкой, при равенстве — более поздняя. Если все оценки ниже 8, возвращается лучшая версия с сообщением, что порог не достигнут.

В Work ведущий агент действительно вызывает нового субагента на каждом проходе. Он передаёт исходные вводные, согласованный состав объектов, референсы, требования и текущий кандидат, без предыдущих оценок. Если нужная модель или механизм субагентов недоступны, ревью считается невыполненным.

CLI `build_prompt.py` собирает текст и не имеет собственного подключения к моделям. Для приложения функция `run_review_loop(initial_prompt, review, revise, expected_targets)` выполняет цикл через две переданные функции: `review` запускает реального независимого рецензента с заданной моделью и возвращает JSON, `revise` дорабатывает промпт. Контекст и вложения закрепляются в этих функциях на весь цикл; `expected_targets` берётся из согласованного состава до первого ревью. Функция проверяет оценки, сохраняет все версии в `history` и возвращает лучшую с полями `prompt`, `score`, `iteration`, `passed`. Ошибки запуска не заменяются вымышленными оценками.

Полный контракт рецензента хранится в `01_Общие_правила_метапромпта.md`; параметры отдельных категорий — в их модулях. В текст для генератора эти инструкции и результаты ревью не включаются.

## Единые исходники

Общий порядок поиска, ревью и ответа хранится только в `01_Общие_правила_метапромпта.md`. Мастер управляет разделом, модули — содержанием объектов и единым чек-листом их генерации и ревью.

Автономные метапромпты собираются из `standalone_template.md`, общих правил и одного модуля:

```bash
python3 build_prompt.py --standalone фото -o photo_metaprompt.md
python3 build_prompt.py --sync-standalone
```

Вторая команда обновляет четыре автономных файла, перечисленных в `categories.json`, не меняя исходники. Автономные файлы не редактируйте отдельно: правьте общий блок, шаблон или модуль, затем повторяйте синхронизацию.

Автономный режим принимает только поля `product`, `audience`, `section`, `references`, `identity`, `format`. Поле `section` здесь содержит задачу отдельного изображения, количество, обязательные элементы и ограничения.

Модули не включают автономные версии, общие вводные и общую композицию повторно. В выходном промпте нет алгоритмов поиска, оценок и ссылок на файлы модулей — только выбранные решения.

## Добавление категории

Добавьте модуль и запись в `categories.json`:

```json
"Название категории": {
  "file": "имя_модуля.md",
  "aliases": ["короткое имя"],
  "standalone_file": "имя_автономной_версии.md"
}
```

`standalone_file` необязателен. Новый модуль должен содержать только свой поиск, критерии оценки и состав описания выбранного элемента. Общие правила наследуются.

```bash
python3 build_prompt.py --list
python3 -m unittest -v test_build_prompt.py
```

Старый вызов Python сохраняется:

```python
from build_prompt import build_prompt
metaprompt = build_prompt(
    ["Общее фото", "Иллюстрация"],
    inputs={"product": "Описание", "existing_sections": "нет"},
)
```

`--prompts-dir` и `--catalog` позволяют выбрать другую папку исходников и каталог. Неизвестная категория вызывает ошибку, а не скрытую замену.

## Контрольный пример Holdi

- `Holdi_request.json` — вводные без заданных сюжетов.
- `Holdi_metaprompt.md` — точный результат скрипта.
- `Holdi_generation_prompt.md` — выбранные решения, оформленные в готовый промпт текстовой моделью.
- `Проверка_метапромптов.md` — результаты проверки и ограничения примера.

Изображение по этому примеру не генерировалось. Его пересборка сама по себе не означает прохождение нового независимого ревью. Реальные результаты контрольного запуска указаны в `Проверка_метапромптов.md`. Оценка текста не заменяет визуальную проверку результата генерации.

В архив включены актуальные исходники, синхронизированные автономные версии, тесты и контрольный пример. После правок нужно пересобрать архив; он не обновляется автоматически. Старый `Промпт_лендинга_без_ИИ-слопа.md` — отдельный ранний сценарий всей страницы, не часть этой сборки.
