# Объекты для генератора лендингов

Для твоего генератора я бы предусмотрел **два набора объектов: визуальные материалы и функциональные элементы страницы.** Фото на главную — один из вариантов: там также может быть интерфейс, предметная композиция, видео или их сочетание.

**Визуальные материалы:**

| Объект | Что нужно уметь создавать |
|---|---|
| **Предметная или метафорическая сцена** | Оригинальная композиция, передающая идею предложения: например, ноутбук на огромной стопке потёртых книг |
| **Фото продукта** | Товар на чистом фоне, в окружении, в использовании; разные ракурсы и крупные детали |
| **Общее фото** | Как выполняют работу, из каких этапов она состоит, что получает клиент |
| **Люди и портреты** | Эксперт, основатель, команда, персонажи в жизненных ситуациях |
| **Места и пространства** | Интерьер ресторана, отель, помещение, площадка мероприятия |
| **Интерфейс продукта** | Экран приложения, личный кабинет, чат, календарь, редактор, панель управления |
| **Фрагмент интерфейса** | Одна выразительная часть: ответ ИИ, карточка заказа, уведомление, результат поиска |
| **Мокап** | Интерфейс внутри телефона или ноутбука; дизайн на упаковке, книге, вывеске |
| **Иллюстрация** | Сюжетная, предметная, коллажная, абстрактная; в едином стиле для всей страницы |
| **Схема / инфографика** | Как работает продукт, этапы процесса, связи, состав предложения |
| **График / визуализация данных** | Динамика показателя, сравнение вариантов, распределение затрат |
| **Демонстрация результата** | До/после, пример готовой работы, образец отчёта, результат обработки |
| **Иконки и небольшие символы** | Возможности, преимущества, категории, шаги |
| **Фоны и декоративные элементы** | Текстуры, паттерны, формы, подложки, разделители секций |
| **Логотип и элементы айдентики** | Название в фирменном написании, знак, дополнительные графические элементы |
| **Видео и анимация** | Демонстрация продукта, движение предметов, анимация интерфейса, короткая сюжетная сцена |

**Функциональные элементы самой страницы:**

- **Навигация:** меню, якоря, переключатель языка.
- **Целевое действие:** кнопка, форма заявки, запись, предзаказ, оплата.
- **Представление предложения:** карточки возможностей, тарифы, таблица сравнения, состав комплекта.
- **Интерактив:** калькулятор, квиз, переключение вариантов, демонстрация продукта.
- **Раскрытие информации:** вкладки, FAQ, галерея, слайдер.
- **Доверие:** отзывы, кейсы, рейтинги, логотипы клиентов, сертификаты — на основе предоставленных материалов.

**Ещё важная способность — собирать несколько объектов в одну композицию.** У раздела должен быть один главный визуальный центр; остальные объекты подчиняются ему и выполняют отличающиеся роли. Несколько объектов не должны превращаться в несколько параллельных сюжетов.

Для каждого визуального объекта полезно задавать: **что он объясняет, какую идею передаёт, какой у него стиль, где он расположен и нужен ли прозрачный фон.** Перед сборкой применяется тест удаления: если без объекта смысл, доказательство, действие и узнаваемость не ухудшаются, объект не включается. Свободное пространство не заполняется случайным декором.
