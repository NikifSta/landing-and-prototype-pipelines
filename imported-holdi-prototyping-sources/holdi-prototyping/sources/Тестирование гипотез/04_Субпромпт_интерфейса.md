## Модуль: интерфейс продукта

Задача — выбрать и описать один экран или законченный фрагмент для каждого назначенного объекта. Используй общий порядок поиска и оценки; не проектируй окружающий лендинг.

### Поиск

Определи один пользовательский сценарий, главный рабочий объект, основное действие и показываемое состояние. Сравни три разные структуры экрана, оставляющие только нужную для этого сценария информацию.
Если дан обязательный реальный интерфейс, не переделывай его: выбирай допустимые экран, масштаб и кадрирование.

### Чек-лист генерации и ревью

- Понятны один сценарий, главное действие и результат.
- Максимальная простота: каждый блок нужен для заданного сценария; нет дашборда, боковой панели, графиков и карточек, добавленных по привычке.
- Функции достоверны, реальный обязательный интерфейс сохранён.
- Визуальная иерархия ясна. Необычность навигации не является преимуществом.

### Описание выбранного решения

Зафиксируй экран, состояние, состав и расположение блоков, главный акцент, доступные действия и точные короткие подписи. Примеры данных должны быть нейтральными и не изображать доказанные показатели бизнеса.
Для фрагмента описывай только назначенный участок. Встроенные иконки — части интерфейса, а не отдельный набор вокруг него.
Сохрани реальную дизайн-систему при её наличии; иначе задай последовательное оформление по общим вводным. Не добавляй устройство или перспективу без задания.
Результат работы модуля — конкретное описание экрана для общего промпта, не изображение и не отдельный полный промпт.
