# Мастер-метапромпт раздела лендинга

Подготовь промпт для одного изображения заданного раздела лендинга. Не запускай генерацию изображения.

## Задача мастера

1. Задай композиционную рамку по назначению раздела и применимым приёмам референса: иерархию, относительный масштаб текста и изображений, характер шрифта, ширину текстовой колонки, поля и интервалы. Адаптируй их к айдентике, объёму текста и формату.
2. Примени выбранные модули к назначенным элементам. Каждый модуль выбирает только содержание и внутреннее устройство своего элемента, не проектирует раздел заново.
3. Назначь разделу один главный визуальный центр. Размести выбранные элементы в общей композиции и подчиняй остальные элементы главному центру по масштабу, контрасту и детализации. Для иллюстрации задай положение относительно связанных с ней элементов раздела и размер, соответствующий её роли. Согласуй палитру, размеры, ритм, читаемость, свободное пространство и CTA.
4. Проведи общий проход сокращения после работы всех модулей. Перечисли все самостоятельные объекты и заметные вспомогательные детали, проверь роль каждого и примени тест удаления из общих правил. Удали случайное заполнение пустот, параллельные метафоры, повторяющиеся способы объяснения одной мысли и незаказанный текст. Сохрани согласованные категории и количество, но объединяй их в одну иерархичную композицию без отдельных конкурирующих сюжетов.
5. Собери один промпт из принятых решений. Общие параметры укажи один раз, каждому самостоятельному объекту дай конкретное описание. Зафиксируй исчерпывающий состав кадра и запрет генератору добавлять другие заметные объекты, декоративные надписи или новые смысловые центры.

Готовые разделы — контекст, не часть нового изображения. Сохрани их визуальный язык и согласуй стык. Если это продолжение, не добавляй повторную шапку или меню.
Будущее изображение показывает раздел прямо, без браузерной рамки и внешнего мокапа, если во вводных не задано иное.
Состав категорий уже выбран на предыдущем этапе. Не выбирай его заново, не превращай внутренние детали выбранного объекта в новые категории и не добавляй элементы для заполнения пустот.
