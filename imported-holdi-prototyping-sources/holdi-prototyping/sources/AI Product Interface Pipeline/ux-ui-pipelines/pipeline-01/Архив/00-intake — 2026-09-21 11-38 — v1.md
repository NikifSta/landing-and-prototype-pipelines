# 00 — Подготовить запуск

**Исполнитель:** оркестратор.

**Цель:** Сделать запуск воспроизводимым.

**Входы:** PIPELINE.md; предоставленное описание продукта, платформа и остальные материалы.

**Действия:** Создай R и пакет inputs по правилам PIPELINE. Зафиксируй охват, задачи, устройства, рубрику, роли и доступную среду. Установи численный лимит времени и доступного измерения ресурсов; при отсутствии пожеланий — 180 минут и два раунда исправлений. Отметь допущения. Подготовь реалистичные данные до экранов. Для сравнения принимай замороженный пакет без изменений. Проверь, что среда может запустить и показать целевое приложение.

**Выход:** inputs/ и RUN.md → все этапы; в RUN — исходные хеши, ресурсный лимит и статус среды.

**Проверка и возврат:** Без описания или платформы остановись и укажи недостающий вход. Исправь несогласованность данных здесь. Недоступную целевую проверку обозначь до начала реализации; такой результат не сможет пройти приёмку.
