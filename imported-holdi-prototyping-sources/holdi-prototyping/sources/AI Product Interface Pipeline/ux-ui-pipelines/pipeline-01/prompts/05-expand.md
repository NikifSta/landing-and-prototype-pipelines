# 05 — Распространить систему

**Исполнитель:** frontend-исполнитель.

**Цель:** Завершить весь согласованный интерфейс.

**Входы:** C; MODEL.md; DESIGN.md; REFERENCES.md; prototype/; inputs/DATA.json.

**Действия:** Распространи проверенные композиционные правила и компоненты на оставшиеся экраны. Сохрани рабочие локальные операции и связи данных. Добавь требуемые состояния, адаптацию, способы ввода и функциональное движение. Необходимые изображения подготовь отдельно и проверь после встраивания. Повторно пройди по одному представителю каждого типа экрана.

**Выход:** Законченный prototype/ и актуальные MODEL.md, DESIGN.md → полная проверка.

**Проверка и возврат:** Сверь покрытие MODEL. Новую структурную проблему верни в 01/03, неприменимую визуальную систему — в 04; локальный дефект исправь здесь.
