# 02 — Выбрать компонентную основу

**Исполнитель:** frontend-архитектор и дизайнер.

**Цель:** Найти зрелую основу, совместимую с продуктом и целевой платформой.

**Входы:** C; REFERENCES.md; inputs/DATA.json.

**Действия:** По актуальной официальной документации сопоставь две подходящие основы: семантика, ввод/фокус, состояния, адаптация, кастомизация и доступность зависимостей. Для native рассматривай компоненты целевой платформы. Реализуй одинаковую небольшую пробу из трёх необходимых продукту контролов на данных продукта. Проверь их поведение в целевой среде. Выбери одну основу и закрепи версии.

**Выход:** components/ с пробами; выбор, версии, ограничения и ссылки в DESIGN.md → адаптация системы.

**Проверка и возврат:** Успешная демо-картинка не подтверждает поведение. Если обе основы мешают ключевой задаче, пересмотри выбор здесь в общем бюджете.
