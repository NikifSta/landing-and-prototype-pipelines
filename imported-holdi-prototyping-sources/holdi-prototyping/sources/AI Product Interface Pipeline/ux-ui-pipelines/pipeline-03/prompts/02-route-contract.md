# 02 — Выбрать представительный маршрут

**Исполнитель:** продуктовый дизайнер.

**Цель:** Выбрать небольшой маршрут, проверяющий ключевую ценность и сложные связи.

**Входы:** C; REFERENCES.md; inputs/DATA.json.

**Действия:** Выбери важный обычный сценарий с естественным входом, содержательной работой с данными и видимым результатом. Укажи сущности, начальные данные, переходы, состояния и связи с оставшимися задачами. Сохрани список всех сценариев охвата и порядок их дальнейшей сборки. Зафиксируй, какие решения первый маршрут пока не проверяет.

**Выход:** MODEL.md: подробный контракт первого маршрута и перечень остальных → реализация и расширение.

**Проверка и возврат:** Маршрут демонстрирует ценность продукта, а не только вход/настройки. Непредставительный маршрут замени здесь.
