# 05 — Развить выбранное решение

**Исполнитель:** дизайнер и frontend-исполнитель; reviewer образца.

**Цель:** Превратить выбранную гипотезу в согласованную систему всего приложения.

**Входы:** C; REFERENCES.md; inputs/DATA.json; выбранный пользователем кандидат из RUN.md и оценка из selection/.

**Действия:** После SELECTION_CONFIRMED перенеси исходники выбранного кандидата в prototype и развивай их. Допиши MODEL для всех сущностей, связей, сценариев и состояний охвата. Оформи DESIGN, проверь переносимость системы на трёх образцах. Полезное решение другого кандидата используй только при совместимости с основной моделью и повторной проверке изменённого образца. Reviewer проверяет систему до расширения.

**Выход:** MODEL.md, DESIGN.md, prototype/ и evidence/ → полная сборка.

**Проверка и возврат:** Сочетание решений сохраняет единый принцип. Несовместимую модель пересмотри здесь; несостоятельную гипотезу верни в 02, в оставшихся раундах исправлений.
