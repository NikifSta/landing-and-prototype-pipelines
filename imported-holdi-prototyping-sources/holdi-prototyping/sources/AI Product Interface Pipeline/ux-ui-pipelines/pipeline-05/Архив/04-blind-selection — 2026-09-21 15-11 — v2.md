# 04 — Слепой отбор

**Исполнитель:** оркестратор и новый независимый reviewer.

**Цель:** Выбрать рабочее решение по наблюдаемому результату.

**Входы:** Правила PIPELINE; inputs/; REFERENCES.md; candidates/; общий охват образцов из 02.

**Действия:** Оркестратор случайно назначает нейтральные метки, сохраняет закрытую карту в selection и даёт reviewer только анонимные сборки, инструкции запуска и требования. Скрывает авторов, гипотезы, историю и оценки. Reviewer проходит одинаковую задачу, осматривает одинаковые состояния и применяет gates к охвату образцов. Сначала отсеивает провалы, затем сравнивает прошедших по рубрике. Разрешён отказ всем.

**Выход:** selection/ с оценками и выбором → развитие; наблюдения в evidence/REVIEW.md → приёмка.

**Проверка и возврат:** Эффектная картинка не компенсирует неработающий маршрут. При отказе всем верни причины в 02/03 в пределах общих раундов исправлений; при незакрытых дефектах после последнего раунда — «не принят».
