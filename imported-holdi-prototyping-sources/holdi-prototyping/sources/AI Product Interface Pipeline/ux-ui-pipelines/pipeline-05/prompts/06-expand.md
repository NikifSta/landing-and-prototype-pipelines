# 06 — Завершить выбранное приложение

**Исполнитель:** frontend-исполнитель.

**Цель:** Распространить прошедшую систему на весь охват.

**Входы:** C; MODEL.md; DESIGN.md; REFERENCES.md; prototype/; inputs/DATA.json.

**Действия:** Собери оставшиеся маршруты и состояния на общей системе. Обеспечь корректные локальные действия, связи данных, адаптацию и способы ввода. Подготовь нужные ассеты и осмотри их внутри интерфейса. Пройди новые маршруты и их пересечения с готовыми. Обнови MODEL и DESIGN по принятым изменениям.

**Выход:** Полный prototype/ и актуальные MODEL.md, DESIGN.md → полная проверка.

**Проверка и возврат:** Системную проблему верни в 05; локальную исправь здесь. Непокрытый сценарий не может быть компенсирован оценками образцов.
