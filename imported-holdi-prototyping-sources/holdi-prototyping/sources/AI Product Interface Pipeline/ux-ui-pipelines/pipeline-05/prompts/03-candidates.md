# 03 — Реализовать кандидатов

**Исполнитель:** пять независимых авторов.

**Цель:** Получить отдельные рабочие варианты ключевого экрана.

**Входы:** C; REFERENCES.md; inputs/DATA.json; личное задание из 02.

**Действия:** Каждый автор работает в своей candidates/<id> и не читает соседние решения. В своём направлении пройди цикл H1–H4 по PIPELINE. Сохрани цепочку в своём DESIGN, оркестратор переносит её в RUN. Выполни переход «От референсов к экрану» по PIPELINE: свяжи детали выбранных источников с собственными токенами и компонентами. Реализуй H4 и общий фрагмент маршрута в целевой среде; сохрани материалы для визуальной сверки. Сохрани модель фрагмента и правила оформления рядом с исходниками. Пройди задачу, подготовь снимки и одинаковый способ запуска/сброса. Авторские оценки в материалы проверки не включай.

**Выход:** В каждой candidates/<id>: MODEL.md, DESIGN.md, prototype/, HANDOFF.md и evidence/ → проверка и выбор на 04.

**Проверка и возврат:** Оркестратор сверяет последовательный поиск, различимость пяти H4, полноту и равные условия. Ошибку кандидата верни его автору, проблему постановки — в 02; все затраты учитываются.
