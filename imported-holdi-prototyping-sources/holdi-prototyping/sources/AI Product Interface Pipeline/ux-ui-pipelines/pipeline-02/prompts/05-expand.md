# 05 — Собрать остальные сценарии

**Исполнитель:** frontend-исполнитель.

**Цель:** Сделать визуальную систему работающим приложением.

**Входы:** C; MODEL.md; DESIGN.md; REFERENCES.md; prototype/; inputs/DATA.json.

**Действия:** Собери остальные маршруты и состояния, переиспользуя проверенный принцип и код образцов. Реализуй локальные действия согласно вводу и обновление связанных представлений. Заверши адаптацию, ввод, фокус и нужные ассеты. Актуализируй принятые правила только при подтверждённом улучшении.

**Выход:** Полный prototype/ и актуальный DESIGN.md → проверка.

**Проверка и возврат:** Каждый сценарий MODEL достижим. Конфликт архитектуры верни в 03, визуальную непоследовательность — в 04; дефект конкретного действия исправь здесь.
