# 02 — Композиционные пробы

**Исполнитель:** визуальный дизайнер.

**Цель:** Проверить несколько способов организовать ключевой экран.

**Входы:** C; REFERENCES.md; inputs/DATA.json.

**Действия:** Возьми ключевой экран из RUN_SPEC. Создай варианты по разделам «От референсов к экрану» и «Выбор ключевого экрана пользователем» в PIPELINE. Для каждого свяжи конкретные детали референсов с его токенами и компонентами в собственном DESIGN. Используй платформенный способ рендера. Для каждого варианта запиши одну гипотезу пользы; выбор пока не фиксируй.

**Выход:** studies/ с исходниками, DESIGN каждого варианта и снимками; гипотезы в RUN.md → проверка задачами на 03.

**Проверка и возврат:** Все пробы читаемы на минимальном размере и содержат требуемые данные. Различия только в цвете/радиусах требуют пересборки здесь.
