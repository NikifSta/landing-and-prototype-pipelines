# 02 — Композиционные пробы

**Исполнитель:** визуальный дизайнер.

**Цель:** Проверить несколько способов организовать ключевой экран.

**Входы:** C; REFERENCES.md; inputs/DATA.json.

**Действия:** Выбери ключевой экран по главной задаче. Разбери полезные принципы выбранных референсов. Создай три редактируемые пробы с одинаковым содержанием, различающиеся иерархией, плотностью, компоновкой и фокусом действия. Используй платформенный способ рендера. Сравни их также без цвета. Для каждой запиши одну гипотезу пользы; выбор пока не фиксируй.

**Выход:** studies/ с исходниками и снимками; гипотезы в RUN.md → проверка задачами на 03.

**Проверка и возврат:** Все пробы читаемы на минимальном размере и содержат требуемые данные. Различия только в цвете/радиусах требуют пересборки здесь.
